## AI 输入的数据流

```
stock_code (如 603063)
     │
     ▼
┌─────────────────────────────────┐
│  NewsClient.gather_news()       │
│  ├─ 个股新闻 stock_news_em()   │  ← AKShare 东方财富，10条
│  │   (标题+内容+时间+来源)       │
│  └─ 宏观快讯 stock_info_global_em() │  ← AKShare，10条
│      (标题+摘要+时间)           │
└─────────────────────────────────┘
     │
     ▼
┌─────────────────────────────────┐
│  NewsClient.format_news_for_ai()│  ← 截断内容200字摘要150字
│  输出文本示例                   │
│  【603063 个股新闻】             │
│  1. 禾望电气：净利润同比增35%    │
│     公司发布年报...              │
│  2. ...                         │
│  【宏观财经快讯】                │
│  1. 央行降准0.5个百分点          │
│     释放长期资金约1万亿元...     │
└─────────────────────────────────┘
     │
     ▼
┌─────────────────────────────────────────┐
│  构建 user_prompt                        │
│  请分析以下关于 禾望电气（603063）的新闻：│
│   {格式化后的新闻文本}                    │
│   当前股价 25.60，涨跌幅 2.3%          │
└─────────────────────────────────────────┘
     │
     ▼
┌─────────────────────────────────────────┐
│  AI API 调用                              │
│  system 你是A股分析师，输出JSON...       │
│  user   上面构建的prompt                  │
│  → 返回 JSON (sentimentconfidence...)   │
└─────────────────────────────────────────┘
```

## 当前输入内容的边界

 传给AI的 ✅  没传给AI的 ❌ 
------
 个股新闻（标题+内容摘要）  所有技术指标（MAMACDRSIKDJBOLL） 
 宏观财经快讯（标题+摘要）  信号层计算结果（13个技能的BUYSELL） 
 当前股价 + 涨跌幅  市场状态（RISK_ONPANIC等） 
 股票代码 + 名称  仓位生命周期冷却期 

这是有意为之的分工：规则引擎管量化（技术面），AI管定性（新闻面情绪面），两者互不替代。

但有一个潜在问题——AI不知道当前技术面状态，所以可能出现这种情况：股价刚跌破MA60（技术面很差），但新闻里有利好，AI给了 bullish，反而压制了正确的 SELL 信号。

要不要增强 AI 的输入？比如把关键的技术面摘要也传给 AI，让它看新闻的同时也看一眼技术面？这样 AI 可以判断利好新闻 + 技术面破位 = 可能是诱多vs利好新闻 + 技术面完好 = 值得看多。
