## 版本信息
- 基于：v0.6.2
- 更新时间：2026-04-25T02:20:37.952005
- 升级性质：可靠性重构（非功能堆叠）

---

# 一、升级目标（核心）

构建一个“决策一致、行为可控、对自身历史负责”的交易系统

---

# 二、核心问题定义

当前问题：
- 每日独立决策（Stateless）
- 信号驱动 → 决策频繁反转
- 缺乏交易生命周期定义

---

# 三、核心架构升级

Signal Layer → Strategy Layer → Decision → Execution

---

# 四、Strategy Layer

路径：src/core/strategy_engine.py

核心职责：
- 决策约束
- 抗噪过滤
- 行为延迟
- 反转控制

---

## 交易生命周期

FLAT → OPEN → HOLD → EXIT → COOLDOWN

---

## 决策约束

方向惯性：
if position == "LONG" and signal == "SELL" and score < 0.7:
    HOLD

冷却期：
if last_action == "SELL" and days < 3:
    禁止买入

信号确认：
连续2天一致才执行

反转惩罚：
holding_days < 3 → penalty +0.3

---

# 五、Signal Memory

路径：src/core/signal_memory.py

功能：
- 记录5~10天信号
- 判断稳定性

---

# 六、Execution Layer

路径：src/core/execution_engine.py

滑点：
slippage = 0.001 + 2 * volatility

流动性：
volume < avg_volume * 0.5 → 拒绝交易

涨跌停：
limit_up → 不能买
limit_down → 不能卖

---

# 七、回测升级

Monte Carlo：
运行100次不同滑点

输出：
- 平均收益
- 最差收益
- 波动率

---

# 八、接口

decision = decision_engine.run(...)
final = strategy_engine.apply(decision, position, history)

---

# 九、配置

strategy:
  reverse_threshold: 0.7
  cooldown_days: 3
  confirmation_days: 2

---

# 十、设计原则

1. 信号可变，决策稳定
2. 避免频繁反转
3. 关注最差情况
