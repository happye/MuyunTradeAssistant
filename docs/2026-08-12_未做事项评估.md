## 八、akshare API 踩坑（已记 .learnings/LEARNINGS.md LRN-20260812-001）

- `stock_zh_a_gdhs` 参数是日期非代码（传代码 hang）-> 用 `stock_zh_a_gdhs_detail_em(symbol=代码)`
- `stock_margin_detail_sse` 参数是单日期（无 start_date/end_date）-> date-based + 过滤代码
- `AKShareClient._ensure_baostock_login` 不存在 -> 模块级 `from akshare_client import _ensure_baostock_login`
- akshare 无 timeout 必包超时；`with ThreadPoolExecutor` 超时后 shutdown(wait=True) 仍阻塞，要 shutdown(wait=False)
