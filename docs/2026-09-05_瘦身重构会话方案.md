   `_pull` 模式的固有形态，且该文件是 ISS-083 景气度数据通道 + `[数据缺失]` 文本协议区
   （脆弱耦合 §四.3），收益小风险大，不动。
2. **main.py（3509 行）深度拆分**：361 处 console.print 是报告型 CLI 的固有形态，强抽
   helper 需逐行比对输出字节级一致才有意义；本轮只移除 C2 带来的样板，不做结构性拆分。
3. **parse_input 拆派发表**：mode 名字符串是 chat run_command 桥 + confirm 硬门的协议
   （交接文档 §三·🟡），内部重构无用户可感知收益，不动。
4. **第三批危险区**（plan_guard/orchestrator 安全网、benzong scorer、回测隔离、线程超时
   模式、各级缓存语义）：交接文档默认不动，遵守。
