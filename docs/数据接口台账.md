# 数据接口台账

> 用途：chat 行业分析/产业链数据层的**全部外部接口登记处**，供参考、审查、动态更新。
> 每次新增/更换/发现接口失效，**必须更新本文件**（改代码不改进台账 = 半成品）。
> 最近全面实测：2026-08-15 / 2026-08-16（akshare 1.18.51，本项目网络环境，NO_PROXY 直连）

---

## 一、总原则（先读这个）

1. **每个源都可能挂，但挂了不说谎**：所有接口失败 -> `[数据缺失]（原因）` 降级标注，AI 被要求如实转述给用户，禁止编数据
2. **防旧数据**：期货日线最后交易日距今 >15 天 = 休眠合约，标 `[数据过期]` 且不给分位（实例：动力煤 ZC0 停在 2022-12）
3. **不高频打接口**：TTL 缓存 1 小时（失败结果只缓存 5 分钟，避免反复打挂掉的源）
4. **所有网络调用**：daemon 线程 + 超时（akshare 类 25s / THS 板块 18s / 成分股翻页 15s），绝不挂起 chat
5. **输出带数据日期**：每个数字标注来源日期/月份，用户可自行核对

## 五、板块/成分股（THS 通道）

| 环节 | 实现 | 性质 | 风控 |
|------|------|------|------|
| 板块列表 | `ak.stock_board_industry_name_ths()`（90 行业）/ `stock_board_concept_name_ths()`（375 概念） | 爬虫（同花顺公开页） | TTL 缓存 10 分钟 |
| 成分股 | `MarketCache._get_ths_board_stocks_by_name()`（[market_cache.py:461](../src/scanner/market_cache.py)） | **自研爬虫**：py_mini_racer 跑同花顺官方 ths.js 算 v_code cookie（与 akshare 内置 THS 函数同机制）+ 拟人化 UA/Referer + 翻页随机延迟 0.4-0.9s + 限速检测（表格消失->刷新 v_code 重试一次）+ 最多 8 页 + 15s 超时 + TTL 缓存 | 见下 |

**THS 通道诚实评估**：理论上随时可能被封（它不是官方 API）；但 (a) v_code 机制与 akshare 官方 THS 函数相同；(b) v0.8.4 起作为 `bz scan` 主题词模式生产路径运行数月无封禁记录；(c) chat 使用频率低（一次会话几个行业+缓存）；(d) 被封后果=板块节显示"未匹配到板块"，商品锚/宏观/指引照常，AI 明说缺口。**观察点**：若行业板块解析持续"未匹配到"，即 THS 封禁信号 -> 接备用源（候选：baostock 证监会行业，粗但官方）。

## 七、真实缺口（免费源没有，诚实声明，不假装覆盖）

| 数据 | 状态 | 当前代理方式 |
|------|------|------------|
| 动力电池装机量 / 储能装机量 | ❌ 无免费API（2026-08-17 调研确认：电池联盟CABIA每月10-11日发布、国家能源局月度新闻稿形式；国际储能网 mchuneng.in-en.com 按月发结构化文章页但URL每月变，爬取脆弱且违反本项目"不碰脆弱爬虫源"纪律；akshare 无封装） | NEV 渗透率+厂商排产新闻代理（AI 从 get_news 结果中提取装机数字并标注出处） |
| 太阳能/风电装机容量 | ❌ 国家能源局月度新闻稿形式，无API | 同上，新闻代理 |
| SMM 周度产量/库存/开工率 | 付费墙 | 期货仓单+公告新闻 |
| 能繁母猪存栏等养殖高频数据 | 无免费接口 | 价格分位+基差+成本端推断（AI 明说局限） |
| 全社会库存（非交割库） | 付费墙 | 仓单趋势（仅方向参考） |
| 生意社锂现货单品 | akshare 解析 bug | futures_spot_price 品种表 |
| 东财行业板块（_em 系） | 本环境反爬 | THS 通道替代 |

**THS 封禁预案（2026-08-17 实测评估）**：baostock 证监会行业（`query_stock_industry`）实测 84 个门类/大类粒度（C39 电子/C38 电气机械级），**无主题板块粒度（养殖业/白酒/军工均对不上），不适合做板块解析备用源**。THS 若封禁的替代方向：东财 _em 重试（反爬或为间歇性）或新浪行业，均未实测，届时再评估。
