## 一、当前问题（优先排查）

**现象**：`chat` 模式每次提问不输出回答，再次发送"继续"才有结果。

**可能原因**（按概率排序）：

1. **DeepSeek-V4 思考模式 content 空**（最可能）：
   - `deepseek-v4-flash` 默认思考模式，思考时 `content` 可能为空、内容在 `reasoning_content` 里
   - 本会话已加 `thinking.type=disabled`（7 处调用），但可能某处漏了，或 v4-flash 即使 disabled 也偶尔返回空 content
   - 第一次提问返回空 content -> chat 输出空；再发"继续"，AI 基于历史（已有空回复）重新生成 -> 有 content -> 有结果
   - **排查**：开 AI debug 模式（`ai.debug: true` 或 `debug` 命令）看 API 返回的 `finish_reason` / `content` / `reasoning_content` 三个字段

2. **finish_reason=length 截断**：
   - 长回答被 max_tokens 截断，代码已加截断检测（追加"⚠️ 已截断"提示），但可能 content 为空时检测不到
   - **排查**：看返回的 finish_reason 是否是 length

3. **timeout=180s 超时**：
   - 长回答生成 >180s 超时 -> 无回答。再次发"继续"是短回答 -> 有结果
   - **排查**：看是否 APITimeoutError

4. **content 为空时无兜底**：
   - `_run_conversation` 拿到 `message.content or ""`，如果 content 为 None/空且无 tool_calls，返回空字符串 -> chat 输出空
   - **应加兜底**：content 空时检查 `reasoning_content`，用 reasoning_content 作回答（项目 ai_modifier.py 已有此兜底模式 `_parse_response`，chat 层没抄）
