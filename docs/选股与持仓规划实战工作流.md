# 选股与持仓规划实战工作流（v0.8.6.5）

> 把工具的全部能力串成一条完整流程：选股 → 评分 → 建仓 → 持有 → 离场。
> 面向"想用这套工具真正做决策"的用户，5 分钟能看完一条主线。
> 命令细节见 [使用手册.md](../使用手册.md)，评分原理见 [笨总6维评分_说明文档.md](笨总6维评分_说明文档.md)，持有纪律见 [TradePlan_使用指南.md](TradePlan_使用指南.md)。

---

## 核心理念（先理解再用）

这套工具的决策主驾是**笨总「超景气价值投机」体系**，不是技术指标。流程是：

1. **笨总选股**：6 维评分筛出"高景气行业里的纯正龙头"，分级 A/B/C/D/F
2. **笨总定 mode**：建仓时按评级定持有性格——A级气宗(长持180天拿住整波)、B级剑宗(短线30天破线即走)
3. **硬规则锁持有**：持有期不靠 AI 实时判断，靠客观规则——气宗压制技术卖出 + 高位止盈3维度强制离场 + 致命止损兜底
4. **技术层降级为择时**：Chandelier trailing 止损、买卖点精确触发，只作持仓内的择时工具

**关键边界（回测验证）**：气宗是**牛市/主升浪武器**，在调整/熊市会死扛下跌有害。当前若处震荡市，慎用气宗（见末尾「不同市况的用法」）。

## 第1步：选股 — `bz scan <主题词>`

**何时用**：想找某个赛道（材料/技术/概念）的标的时。

```
bz scan 氮化镓,钽电容          # 双通道选股：法C(AI报股) + 全市场行业筛选(含中小盘)
bz scan 钢铁,煤炭 --top 10     # 限制 Top10
bz scan AI,半导体 --limit 15   # 限制候选数控制 AI 耗时（默认15）
```

**双通道**（去龙头偏向）：
- 通道A 法C：AI 报出真正做这个方向的 A 股公司，Baostock 验证代码真实。覆盖 PBO树脂等细分材料
- 通道B 全市场筛选：从同花顺行业/概念成分股捞**全市场**成员（含中小盘非龙头，不靠 AI 记忆）

**怎么读排名表**：

```
┃ #   ┃ 代码   ┃ 名称   ┃ 评分 ┃ 等级   ┃ 置信度 ┃ 行业景气/纯度/估值/龙头/辨识/风险 ┃
│ 1   │ 300347 │ 泰格   │  76  │  A     │  0.60  │ 70/100/45/80/70/0                 │
│ 2   │ 600276 │ 恒瑞   │  67  │ C(原A) │  0.70  │ 30/100/85/90/100/0                │
```

- **评分**：归一化到 0-100（原始总分上限 144，无直觉，已压缩）
- **等级**：用 `effective_grade`（含行业景气度硬闸门）。景气度≤30 标红 + 标注「原X级」——表示"虽总分够 A，但行业不景气，实际降级"
- **行业景气度**（第一列）：**最重要的一维**。笨总大前提：景气度=0 模型失效；≤30 边际下行不能买

**选股判读**：
- 先看行业景气度这一列，景气≤30 的即使评级 A 也别买（被闸门降级了）
- 别只看"全 A 级"就买——可能是入口只放了龙头进来，或都是好公司但此刻不该买
- 横向差异比"都是A"重要：泰格景气70 vs 恒瑞景气30，这个差距比评级更关键

## 第2步：细看候选 — `bz <代码>`

**何时用**：scan 选出 Top 候选后，对感兴趣的逐只细看 6 维。

```
bz 600519            # 6 维 AI 自动评分（约 30-60s）
bz 600519 --refresh  # 强制刷新跳过缓存
```

**输出要点**：
- 每维 `✓` 出真实分 / `⚠` 降级（数据缺失或 AI 失败，分不可信）
- `confidence` 0-1 该维可信度，纯算法维（估值位置）恒 1.0
- 总体置信度 = 6 维最低值，<0.5 说明有维度降级，总分仅供参考
- `⚠ 大前提失效`（行业景气=0）：总分/等级不具参考意义，不可作买入依据

**细看判读**：
- 业务纯度（权重40%最重要）：区分真主营 vs 蹭概念
- 历史估值位置：离3年最低价涨幅>120% 判0分（已涨太多，估值偏高）
- 个股风险值：减持/解禁/官司/造假等，0=无风险（注：新闻拉取失败时显中性50+标红，非0）

## 第3步：建仓 — `pos add <代码>`

**何时用**：决定买某只股，录入持仓 + 自动生成交易计划。

```
pos add 002192 融捷股份 35.20 0.20    # 代码 名称 成本价 仓位比例
```

**自动流程**：
1. 系统跑笨总评分，按 `effective_grade` 自动定 mode：
   - A级（景气>50）→ **气宗**（max_hold=180天，宽止损2×ATR，失效条件只留致命止损）
   - B级 → **剑宗**（max_hold=30天，紧止损1×ATR，跌破MA20即走）
   - C级以下 → 不定 mode（仅压 weak_sell）
2. 生成 TradePlan 草稿，展示 why_buy/止盈分档/止损/max_hold/mode
3. Y/n 确认是否采用

**⚠ 手动改 mode（当前震荡市常用）**：

`pos add` 目前**没有 `--mode` 参数**，mode 完全由笨总评级自动定。若你想手动覆盖（如震荡市想强制剑宗避气宗）：

1. `pos add` 时在 Y/n 确认那步选 **n**（不采用自动 plan）
2. 手动编辑 `portfolio.yaml`，找到该股的 `trade_plan` 段：
   ```yaml
   trade_plan:
     mode: jianzong          # 改成 jianzong
     max_hold_days: 30       # 同步改成30
     locked_initial_stop: ... # 紧止损(可重算 entry-1*ATR)
   ```
3. 或建仓后跑 `pos plan <代码> --update`，但 update 会沿用旧 mode（不重跑评分），所以仍需手动改 yaml

**这是已知的易用性缺口**，后续考虑加 `--mode` 参数。当前变通靠手动编辑 yaml。

## 第4步：持有监控 — `pos plan` + `l <代码>`

**日常监控命令**：

```
l 600519                # 单股分析：技术面+PlanGuard 是否压制+笨总评分摘要
pos plan 600519         # 查看该股的完整计划（止损/止盈/失效条件/max_hold/mode）
pos plan 600519 --update # 行情变动后按当前行情更新计划（保留建仓日，止损单向上移）
pos plan all --update   # 批量刷新所有持仓计划（适合定期维护，如每月一次）
scan                    # 扫描所有持仓股的技术面状态
```

**持有期间发生了什么**（PlanGuard 守卫）：
- **气宗**：压制 weak_sell/trend_exit/take_profit_trim → 回调时被压住不卖，拿住整波主升浪
- **剑宗**：只压 weak_sell，破线即走
- **不可压制的安全网**（所有 mode 都生效）：
  - P0 致命止损：价格 ≤ current_stop → 强制 SELL
  - P1 高位止盈3维度：成交额破10万亿 / 换手>40% / 缩量加速 / 实控人减持 → 强制 SELL
  - P2 时间止损：持有 ≥ max_hold_days → 强制 SELL

**何时 --update**：持仓一段时间后行情变动（趋势转好/转坏、ATR 变化），旧计划的止损/止盈可能过时。`--update` 按当前行情重算，**保留建仓日期 + 止损单向上移**（不会把止损拉低）。注：update 沿用旧 mode，不重跑笨总评分（避免纪律摇摆）。

## 第5步：离场信号

工具会在以下情况强制或建议离场，`l <代码>` 的输出会标明：

| 信号 | 优先级 | 说明 |
|------|--------|------|
| 致命止损（价格≤current_stop） | P0 不可压 | 最硬兜底，气宗也挡不住 |
| 高位止盈3维度 | P1 不可压 | 大顶信号：宏观成交额破10万亿/个股换手>40%/缩量加速/实控人减持 |
| 时间止损（≥max_hold_days） | P2 不可压 | 气宗180天/剑宗30天到期 |
| 基本面恶化 | 解除压制 | outlook转bearish后，气宗不再压制技术卖出（注：当前需手动改 outlook，自动监测是阶段3未做） |
| 技术weak_sell/trend_exit | P3 气宗压制 | 气宗压住不卖，剑宗放行 |

**注**：高位止盈3维度的"换手>40%/实控人减持"在震荡市可能误触发（活跃市换手普遍高），需结合成交额综合判断。

## 不同市况的用法（重要）

回测验证（批次1+批次2）证明：**气宗在牛市/主升浪有效（+8.13pp），在调整/熊市有害（-0.46pp，死扛下跌）**。所以用法要随市况调整：

### 牛市 / 主升浪（沪深300上行，成交额持续放量）
- ✅ 正常用气宗：`pos add` 自动定气宗的，Y 确认
- ✅ 拿住牛股不卖飞，靠高位止盈3维度逃顶
- 这是工具的**最佳适用场景**

### 震荡市 / 洗盘（指数横盘，日内剧烈波动，成交额高位）
- ⚠️ **慎用气宗**：震荡市气宗死扛风险大。`pos add` 若定气宗，手动改剑宗（编辑 yaml，见第3步）
- ⚠️ 警惕科技股抱团：`bz scan` 选出的高景气科技股可能已拥挤，工具无抱团度信号，自己判断"是不是太热"
- ✅ 关注成交额信号：从高位回落时往往是洗盘结束
- ✅ 剑宗（短持30天）在震荡市更适合——快进快出

### 熊市 / 调整（沪深300下行）
- ❌ **别用气宗**：批次2证明气宗在调整年有害（宁德2023/神华2023 都恶化）
- ✅ 用剑宗或不建仓
- ✅ 致命止损会兜底，但别依赖气宗压住下跌

### 怎么判断当前市况
- 跑 `bz --check` 看数据源，或看 `l <任意股>` 输出里的 MarketState（牛市/震荡/熊市/恐慌）
- 看全市场成交额：`bz scan` 评分时会显示流动性系数（≤0.8万亿缩量/≥1.5万亿放量）
- 沪深300 是否在年线上方（牛市分界）
