# 暮云思辨投资助手 — 实盘操作指南

## 一、回测盈利 ≠ 未来稳定盈利（必须知道的事）

### 为什么回测盈利不能保证未来？

回测是用**历史数据**验证策略逻辑，它只能证明"过去有效"，不能保证"未来有效"。这是所有量化工具的共识，不是我们工具的问题。核心原因：

1. **过拟合风险** — 如果策略参数刚好"拟合"了那段历史行情，换个时段可能完全失效
2. **市场环境变化** — 牛市有效的策略在熊市可能亏钱，震荡市有效的策略在趋势市可能踏空
3. **流动性假设** — 回测假设开盘价无限成交，实盘可能有冲击成本、涨停买不到、跌停卖不出
4. **心理偏差** — 回测里你不会恐慌割肉，实盘里连跌5天时你很难不动摇

### 行业公认的回测评估框架

机构验证策略可靠性有**一套标准流程**，以下是我们应该参考的：

#### 1. 样本外测试（Out-of-Sample Test）⭐ 最重要

| 做法 | 说明 | 我们能做到吗 |
|------|------|-------------|
| 训练集/测试集分割 | 用2023-2024调参，用2025验证 | ✅ 用`-s`和`-e`指定不同区间 |
| 多时段测试 | 至少跑3个不同市场环境（牛/熊/震荡） | ✅ 手动切分时段回测 |
| 多标的测试 | 同一策略跑10只以上不同股票 | ✅ 每只股票单独`-l`或`-b` |

**你的操作**：
```powershell
# 测试1：牛市区间（2024.9-2024.10）
python -m src.cli.main -b 002192 -s 2024-09-01 -e 2024-10-31

# 测试2：熊市区间（2023.8-2024.02）
python -m src.cli.main -b 002192 -s 2023-08-01 -e 2024-02-29

# 测试3：震荡区间（2024.03-2024.08）
python -m src.cli.main -b 002192 -s 2024-03-01 -e 2024-08-31
```

#### 2. 关键指标门槛

| 指标 | 及格线 | 良好 | 说明 |
|------|--------|------|------|
| 夏普比率 | >0.5 | >1.0 | 风险调整后收益，越高越好 |
| 最大回撤 | <25% | <15% | 从高点到低点的最大亏损 |
| 胜率 | >40% | >55% | 盈利交易占比 |
| 盈亏比 | >1.5 | >2.0 | 平均盈利/平均亏损 |
| 跑赢基准 | >0% | >5% | 对比买入持有 |

> 如果某个指标不达标，不代表策略不能用，但需要理解为什么不达标。

#### 3. 稳定性检验

- **参数敏感性**：把止损阈值从0.8改到0.75或0.85，收益变化大不大？变化小说明策略稳健
- **不同市值**：大盘股/中盘股/小盘股分别测，看策略在哪个市值范围最有效
- **交易频次**：一年交易少于5次说明信号太少，多于50次说明过于频繁

#### 4. 我们目前缺少什么

| 缺失项 | 重要性 | 实现难度 | 说明 |
|--------|--------|----------|------|
| 多股批量回测 | ⭐⭐⭐ | 中 | 目前只能单只回测，需要手动一只一只跑 |
| 参数敏感性分析 | ⭐⭐ | 低 | 修改settings.yaml参数后重新回测 |
| 周线/月线过滤 | ⭐⭐⭐ | 高 | 策略库核心"月线定方向→周线定位置→日线找买卖点"只实现了日线 |
| 分行业/分市值回测 | ⭐⭐ | 中 | 需要分类数据源 |

## 二、每日实盘操作流程

### 📅 交易日作息表

#### 🌅 开盘前（9:00-9:25）— 不用操作

策略是日线级别，开盘前不需要做任何事。集合竞价波动大，不适合我们的策略。

#### 📊 盘中扫描（9:30-14:00）— 可选

如果你持有某只股票，想看盘中走势是否符合预期：

```powershell
# 查看持仓股的实时分析
python -m src.cli.main -l 002192

# 查看备选股
python -m src.cli.main -l 600519
```

**盘中分析的注意点**：
- 数据是"半成品"（当前价代替收盘价），结论可能和收盘后不同
- 主要看**方向**：偏多/偏空/观望，不要据此精确操作
- 如果盘中信号突然从BUY变成SELL，可能是跌幅扩大，注意风险

#### 🔔 尾盘决策（14:30-14:50）— 核心操作窗口

这是**最关键的操作时间**。原因：
1. 接近收盘，当日K线基本定型，分析结果接近收盘后
2. 如需下单，还有10-30分钟操作时间
3. 策略库的"尾盘操作"理念——避开盘中波动

```powershell
# Step 1: 查看持仓股
python -m src.cli.main -l 002192

# Step 2: 查看结果中的关键信息
# ┌─────────────────────────────────────────┐
# │ 决策: BUY / WATCH / SELL               │  ← 核心信号
# │ 仓位动作: OPEN/ADD/REDUCE/CLOSE_ALL     │  ← 仓位建议
# │ 目标仓位: 20%/40%                        │  ← 建议仓位比例
# │ 决策追溯: 6步路径                         │  ← 为什么给这个信号
# └─────────────────────────────────────────┘
```

**决策对照表**：

| 决策信号 | 仓位动作 | 含义 | 你的操作 |
|----------|----------|------|----------|
| BUY | OPEN | 空仓→建仓 | 用20%资金试探性买入 |
| BUY | ADD | 持仓→加仓 | 加到40%仓位（趋势确认） |
| WATCH | HOLD_POSITION | 继续持有 | 不操作，安心持有 |
| WATCH | STAY_OUT | 继续观望 | 不操作，等待信号 |
| SELL | REDUCE | 弱卖出→减仓 | 卖出部分，留65%底仓 |
| SELL | CLOSE_ALL | 强卖出→清仓 | 全部卖出 |

#### 📝 收盘后复盘（15:05-15:30）— 每日必做

收盘后数据最完整，这是**确认信号和记录日志**的时间。

```powershell
# Step 1: 收盘后确认持仓股信号
python -m src.cli.main -l 002192

# Step 2: 扫描自选股（如果有多个关注标的）
python -m src.cli.main -l 600519
python -m src.cli.main -l 000858

# Step 3: 记录今天的决策
# 在你的交易日志中记录：
# - 日期、股票、信号、是否执行、执行价格
# - 如果没有执行，记录原因（如"尾盘没来得及"）
```

#### 📅 周末（可选）— 深度回测

```powershell
# 回测关注股票的近期表现
python -m src.cli.main -b 002192 -s 2025-01-01

# 回测不同时段，验证策略稳定性
python -m src.cli.main -b 002192 -s 2024-01-01 -e 2024-06-30
python -m src.cli.main -b 002192 -s 2024-07-01 -e 2024-12-31
```

### 🎯 具体信号解读指南

#### 什么时候可以买入？

满足以下**全部条件**时可以考虑买入：

1. **决策 = BUY**，且仓位动作 = OPEN 或 ADD
2. **大盘环境 ≠ RISK_OFF/PANIC**（追溯信息中能看到市场状态）
3. **决策追溯中 base 技能（均线/量价/MACD等）有3个以上看多**
4. **止损信号未触发**（追溯中无止损覆盖）

#### 什么时候应该卖出？

满足以下**任一条件**时考虑卖出：

1. **决策 = SELL + CLOSE_ALL** → 清仓（止损或趋势反转）
2. **决策 = SELL + REDUCE** → 减仓到65%底仓（弱卖出信号）
3. **止损信号覆盖** → 无条件执行（策略库铁律）
4. **仓位 < 5%** → 直接清仓（仓位太小没意义）

#### 什么时候继续观望？

1. **决策 = WATCH** → 信号不明确，不操作
2. **大盘 = TRANSITION**（震荡市）+ BUY信号 → 降级为观望，等趋势明确
3. **追高中** → 如果当日涨幅>5%且信号是BUY，可能是追高，谨慎

---

### ⚠️ 风控红线（任何时候不可突破）

| 规则 | 说明 |
|------|------|
| 单只股票≤总资金20% | 分散风险，不要重仓一只 |
| 止损必执行 | 策略说止损就走，不要"再等等" |
| 不追涨杀跌 | 涨停板不要追，跌停板不要恐慌割 |
| 连续亏损3次→暂停 | 回头复盘策略是否需要调整 |

## 三、从零建仓：不知道买什么时怎么做

### 当前工具的支持情况

| 场景 | 支持程度 | 方法 |
|------|----------|------|
| 已有目标股，判断买卖时机 | ✅ 完全支持 | `-l 代码` 实时分析 |
| 2-3只备选股，对比选择 | ⚠️ 需手动逐个跑 | 分别 `-l 代码A`、`-l 代码B` |
| 完全不知道买什么 | ❌ 不支持 | 工具是"决策辅助"，不是"选股器" |

### 从零开始的操作方法

#### Step 1: 选股（需要你自己做）

工具不帮你选股，但你可以用以下方法缩小范围：

- **板块轮动**：看当天哪个板块领涨，从中选龙头
- **基本面筛选**：PE<30、ROE>15%、营收增长>10%（用炒股软件或财经网站）
- **自选股池**：维护一个5-10只长期关注的股票列表

> 💡 建议：固定一个10只左右的自选股池，每天收盘后逐个扫描。

#### Step 2: 批量扫描自选股

```powershell
# 收盘后逐个扫描（目前需要手动一只一只跑）
python -m src.cli.main -l 002192
python -m src.cli.main -l 600519
python -m src.cli.main -l 000858
python -m src.cli.main -l 601318
# ... 以此类推
```

**扫描时重点看**：
- 决策 = BUY + OPEN → 可以考虑建仓
- 决策 = BUY + ADD → 之前已持有的可以加仓
- 决策 = WATCH → 继续观察
- 决策 = SELL → 已持有的注意风险

#### Step 3: 回测验证（建仓前必做）

不要看到BUY就直接买！先回测确认策略在这只股票上的历史表现：

```powershell
# 回测近1年
python -m src.cli.main -b 002192

# 如果回测收益为负或跑输基准，即使当前BUY信号也要谨慎
# 如果回测收益稳定跑赢基准，当前BUY信号更可信
```

#### Step 4: 建仓执行

确认建仓后：
1. 尾盘14:30-14:50下单
2. 只用20%资金试探（OPEN）
3. 第二天收盘后用 `-l` 确认信号
4. 如果信号继续BUY+ADD，可以加到40%
5. 设置止损位（策略会自动提示）
