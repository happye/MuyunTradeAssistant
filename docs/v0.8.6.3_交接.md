## 三、最重要的诚实结论（下个会话必读）

### 3.1 增量调参已达边际，现有技术架构天花板已现

| 轮次 | 改动 | 收益改善 |
|------|------|---------|
| ISS-033 一轮 | take_profit 参数 | +0.00pp |
| ISS-033 二轮 | MarketState 分档参数 | +0.22pp |
| ISS-033 三轮 | 容量对齐 | +0.19pp |
| ISS-037 五轮累计 | 各种调参 | +1.4pp |
| v0.8.6.3 气宗 | 压 trend_exit 拿住牛股 | +2.46pp（卖飞组）/ -1.94pp（见顶股中免恶化） |

**全部在 +1-2pp 噪声地带**，离趋势牛股 50pp+ 错过缺口差两个数量级。这不是再调一轮能突破的——**七层技术架构是为短期交易设计的（Chandelier/min_hold/冷却期），在中长期任务上是拿短期扳手拧长期螺丝**。

### 3.2 笨总选股不是瓶颈，持有+景气度判定才是

033+笨总验证揭示：4只卖飞牛股笨总全高分（4/4≥70），笨总"会选"它们。但对照组中免（转熊，策略跑赢它是对的）也 A 级 125 分——**笨总分不清"该拿住的回调"和"真在死"**。两者行业景气度都给 30，区分维度实际没起作用。景气度真伪判定正是笨总自己说的"对 AI 极难"。

### 3.3 未拍板的根本决策（留给用户）

用户顾虑3"是否跳出现有思维"已摆到台面但**未拍板**。三个选项：
- **跳法A**：pivot 笨总当中长期决策主驾（选股+持有纪律），技术层降级为持仓内择时。较大重构，是 v0.8.6 调研报告原始意图但从未执行（笨总一直是"旁边看的人"不是"开车的人"）。
- **跳法B**：重新定位工具场景——也许中长期选股+人工决策辅助（而非全自动回测策略）才是定位。
- **不跳**：继续现有架构找杠杆，但验证表明收益边际递减。

**下个会话不要默认继续调参**——先和用户确认这个方向决策。

## 八、踩坑警示（本会话新增，已入 AGENTS.md §五）

- **拼音 benzhong→benzong**：「笨总」的「总」是平舌音 zǒng。曾全局误写翘舌 zh，已修正（目录/import/变量/文档标识符，中文"笨总"不动）
- **curl_cffi SSL curl 77**：项目中文路径致 libcurl 找不到 CA 证书，`fix_curl_ssl_paths` 公共修复
- **Chandelier force_exit 不设 sell_path**：orchestrator 已修，明确标 trend_exit 让 PlanGuard 气宗能匹配
- **PlanGuard 压制须重置 position_action**：否则执行层仍按 REDUCE/CLOSE_ALL 卖出，压制白做
- **AI 评分 JSON 截断**：reasoning 超长致 `Unterminated string`，max_tokens 1500 + finish_reason==length 重试 + `_parse_score_json` 容错
- **suggest_update 名称覆盖**：Baostock stock_data.stock_name 常是代码本身，调 suggest_update 须优先用 pos.stock_name（已修+防御层）
