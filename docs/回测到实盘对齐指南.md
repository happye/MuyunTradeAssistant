# 回测到实盘对齐指南（跳法A 实操版）

> 撰写：2026-08-23 ｜ 适用版本：v0.8.7
> 回答一个问题：**五年回测 + 三批次验证里赚钱的那套纪律，实盘怎么一步步原样跑出来？**
> 前置阅读：[选股与持仓规划实战工作流.md](选股与持仓规划实战工作流.md)（操作细节）、[实盘操作指南.md](实盘操作指南.md)（每日流程）——本文不重复它们，只讲"对齐"。

---

## 一、先记住三个结论

1. **回测和实盘跑的是同一套决策代码**。同一个 `Orchestrator.analyze()` 七层链路（Signal → Decision → Event → AI Modifier → EntryExit → Strategy → PlanGuard → Execution），不是两套逻辑。回测验证的纪律在实盘原生生效。
2. **回测赚钱的核心不是预测，而是"建仓时一次定 mode + 之后机械持有"**。气宗（笨总 A 级股）180 天长持压趋势卖出；剑宗（B 级）30 天紧止损快进快出。你对齐的对象是这套纪律，不是某个具体收益数字。
3. **回测收益 ≠ 你的实盘收益**。三批次都是人工/半自动标注的事后验证，有幸存者偏差（案例是从"当年牛股/见顶股"里挑的）。对齐操作可以复现*行为*，不保证复现*结果*。**2026-08-29 大样本校正**（60 只随机分层 × 4 年 × 720 趟，见 docs/2026-08-29_大规模分层回测矩阵报告.md）：随机股上气宗年均仅 +0.05~+1.9pp，统计优势集中在大盘蓝筹/红利风格（主板大盘 2024 切片 +6.48pp、9/10 正）；主板小盘上两种 mode 均近零期望。**实务结论：小盘仓以 l 命令择时过滤为主、mode 纪律为辅；想用气宗长拿纪律选大盘红利风格的票。**

## 二、回测到底做了什么（对齐的靶子）

以最近的三次验证为例（明细见 ISSUES.md ISS-046 更新记录）：

| 批次 | 区间 | 案例 | 结果 |
|------|------|------|------|
| 批次1 | 2020-2024 五年 | 12 只（牛股/见顶/对照） | 牛股组 Δ+12.32pp 正向 8/8 |
| 批次2 | 2023-2024 | 大中小盘 9 只 | 调整年气宗有害（已知边界） |
| 批次3 | 2026-01~08（含 8/19 暴跌） | 热门板块 8 只 | qizong 5/5 正向平均 +17.3pp |

回测引擎的关键设定（`tests/backtest/test_jumpA_backtest_5year.py` / `test_jumpA_backtest_batch3_2026.py`）：

- `execution_mode="framework_strict"` + `layer_mode="decision_strategy_execution"`：走完整七层链路。
- `enable_trade_plan=True`：TradePlan + PlanGuard 生效（气宗压制 trend_exit/take_profit_trim 的机制就在这）。
- mode 来源：**人工标注**（`benzong_auto_mode=False`）——回测里"这只股是气宗"是人根据当年行情标的。
- 成交模型：**T 日收盘数据出信号 → T+1 开盘价 ±滑点成交**。

## 三、逐项对照：回测 vs 实盘

### 3.1 完全一致的部分（不用操心）

| 项 | 说明 |
|----|------|
| 决策链路 | 同一个 Orchestrator 七层 + PlanGuard，参数同源 `configs/settings.yaml` |
| mode 纪律参数 | 气宗 max_hold≥180天 + 2×ATR 宽止损 + 只有致命止损/时间止损/top_signal 能强平；剑宗 ≤30天 + 1×ATR 紧止损 |
| 高位止盈信号 | 缩量加速、实控人减持、三倍定律等 force-exit 规则同一套代码 |
| 配置文件 | `entry_exit_config`（买卖点）双方都从 settings.yaml 加载；金字塔仓位已按 2026-07-17 审查拍板移除，不再涉及 |

### 3.2 需要你主动对齐的部分（核心）

**(1) mode 怎么来——这是最大的对齐点**

回测里的气宗是人标的；实盘里由**建仓那一刻的笨总评分自动定**（`pos add` 时触发）：

```
笨总 effective_grade = A 且 行业景气度>0 且 Weinstein 阶段∈{S1,S2}  → 气宗(180天)
笨总 effective_grade = B（或 A 但阶段 S3/S4 降级）                  → 剑宗(30天)
景气度≤0                                                          → 不定mode（走原策略）
```
> 补充规则：自主可控标的强制剑宗（`is_self_reliance` 闸门）；阶段数据不足（stage="?"）时 A 级仍判气宗。
> 另注意批次2教训：调整年气宗有害（死扛下跌），mode 有效性强依赖大盘环境——牛市/主升浪里气宗纪律才兑现。

所以对齐动作就是：**只用 `bz scan`/`bz` 选出评分 A 级（且景气度为正）的票建仓**——你选了 B 级票，实盘走的就是剑宗，别指望它复制气宗的回测曲线。建仓后 mode 不再改变（更新 plan 不重跑评分，防纪律摇摆），持有期间**不要手动改 plan 的 mode**。

**(2) 执行时点——信号是 T 日收盘出的**

回测按"T+1 开盘价"成交。实盘对应做法：**当天收盘后跑 `l <code>` / 裸 `pos` 看信号，次日开盘执行**。盘中看到浮亏手动割肉、盘中追涨，都会偏离回测行为（回测没有你的盘中情绪）。

**(3) 资金与仓位档位**

回测初始资金 20 万（金字塔仓位管理已按审查拍板移除，仓位比例由策略层内置参数决定）。资金量差异会改变"一手买不起被拒单"的边界（高价股见 ISS-034 的诊断行）。建议实盘资金与回测假设同数量级，或自行重跑一遍同区间回测校准。

### 3.3 实盘比回测"更强"的部分（live 独有保护）

以下信号因历史数据不可得（point-in-time 红线）在回测中跳过，但**实盘全部生效**：

| live 独有信号 | 作用 |
|--------------|------|
| 股东户数激增 >50% | 筹码分散=主力派发，强制离场 |
| 融资余额 5 日激增 >10% | 杠杆踩踏风险，强制离场 |
| 实控人减持公告扫描（近30天） | 见顶 overhang，强制离场 |
| 缩量加速连续性确认 | 减少单日误判（2026-08-23 增强） |
| fundamental_alert（ST/业绩预亏） | 暴雷硬退出 |
| 板块渗透率 30% 魔咒 + 旗手滞涨 | 板块层逃顶 |

含义：**你的实盘卖出保护比回测更全**。回测里靠致命止损硬扛的场景，实盘可能提前被这些信号救出去。这不是偏差，是安全垫。

### 3.4 无法对齐的部分（诚实声明)

- **AI Modifier**：回测 `ai_enabled=False`，实盘开着 AI 新闻情绪调节——同一根 K 线可能因此给出不同 decision。
- **未来不可知**：批次案例是从已走完的行情里挑的，2026 年下半年不会再有"兆易创新式 H1 主升"等你拿。
- **滑点/流动性**：回测用固定滑点模型；实盘小盘股冲击成本更高。
- **你自己**：回测没有"跌了 -15% 手痒割肉"这个变量。对齐回测最大的敌人不是代码差异，是手动干预。

## 四、实操流程（对齐版每日动线）

```
① 选股   bz scan <主题词>          # 只要 effective_grade A/B 的票进入观察
② 评分   bz <代码>                 # 看 6 维 + 归一化分 + 景气度标红警告
③ 择时   l <代码>                  # Weinstein 阶段 + 买卖点确认（S2 上升期才建仓）
④ 建仓   pos add <代码>            # 自动跑笨总评分定 mode——这一步就是对齐动作本身
⑤ 计划   pos plan <代码|all>       # 生成 TradePlan，PlanGuard 开始值守
⑥ 持有   每天 l <代码> / expect    # 只看不动手；环境温度计给宏观背景
⑦ 离场   信号触发照做              # top_signal/fundamental_alert/致命止损不可压制；
                                   # weak_sell 被 PlanGuard 压制是特性不是 bug
⑧ 复盘   对照 分析报告/chat/ 落盘记录 + 裸 pos 输出  # 偏离计划的手动操作记下来
```

三条铁律（直接来自回测教训）：
1. **气宗持有期内不做主观减仓**——回测 +12.32pp 的全部来源就是"扛住中途洗盘"。手痒卖飞 = 主动放弃策略唯一的 alpha。
2. **剑宗到期/破位就走，不恋战**——批次2 小盘组 -17pp 的教训是反向的：该快的模式拖成慢的。
3. **弱势期/通杀日别开新仓**——`expect` 环境温度计 + 市场宽度通杀信号是给你踩刹车用的（笨总：好公司也跌，但没必要陪跌）。

## 五、常见误区

| 误区 | 事实 |
|------|------|
| "回测 +30pp 所以这票能涨 30%" | Δ 是相对 baseline 的增量，且样本是事后挑的牛市案例；见 ISSUES ISS-046 局限声明 |
| "我自己看线觉得要卖，先卖了再说" | 你卖的那一刻就退出了回测验证过的路径；真要手动管理就不必跑这套系统 |
| "chat 里问一句和 l 命令一样" | chat 与 CLI 已做过三轮参数对账（H1 修复），重大决策仍建议以 `l` 输出为准并交叉核对 |
| "把 mode 改成气宗就能拿住" | mode 由建仓时评分决定，手动改 plan 是自欺——A 级才有气宗的胜率统计支撑 |
