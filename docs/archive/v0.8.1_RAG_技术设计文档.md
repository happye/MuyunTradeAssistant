# 一、设计目标

本RAG系统服务于 v0.8 架构升级，目标：

- 支持 Chat Agent（对话选股 / 查询）
- 支持 Event Layer（新闻解释 / 叙事增强）
- 支持 Strategy Knowledge（策略知识调用）
- 不参与交易决策链（必须隔离）

---

# 二、系统定位（关键原则）

RAG系统职责：

✔ 提供语义检索能力  
✔ 提供上下文增强  
✔ 提供结构化信息来源  

RAG系统不负责：

❌ BUY / SELL 决策  
❌ 技术指标计算  
❌ 实时行情处理  

---

# 三、系统架构

用户输入 / 新闻
        ↓
   Embedding模块
        ↓
   Vector Store（Chroma）
        ↓
   TopK Retrieval
        ↓
   Context Builder
        ↓
   LLM调用
        ↓
输出（解释 / 股票候选 / 结构化信息）
