# 暮云思辨投资助手 — 技术架构文档

> 版本：v0.8.0 | 最后更新：2026-05-04
> 
> 本版本在 v0.7.3 基础上，完成从“规则驱动交易系统”向“信息驱动 + AI辅助决策系统”的升级。
> 核心目标：引入 AI 信息理解能力（非决策）、全市场扫描能力、事件驱动分析能力。

---

# 一、v0.8 核心升级概览

## 1.1 升级目标

v0.7.x 系统已具备：
- 五层架构（Signal → Decision → Strategy → Execution）
- 行为约束（惯性/冷却/生命周期）
- 可回测、可解释

但存在核心缺陷：
- ❌ 无选股能力（Scanner）
- ❌ 无信息理解能力（新闻/叙事）
- ❌ 无动态市场认知（事件驱动）

---

## 1.2 v0.8 新增模块

| 模块 | 作用 |
|------|------|
| Scanner Layer | 全市场扫描候选股票 |
| Ranking Layer | 评分排序 |
| AI Modifier Layer | AI调节信号（不参与决策） |
| Event Layer | 事件驱动（新闻/政策/叙事） |
| Chat Agent Mode | 对话式选股与查询 |

# 三、AI Modifier Layer（核心设计）

## 3.1 设计原则

- AI不参与 BUY/SELL 决策
- AI只影响“变量”
- AI输出必须结构化

---

## 3.2 AI输出结构

```json
{
  "sentiment": "bullish | bearish | neutral",
  "confidence": 0.0~1.0,
  "risk_level": "low | medium | high",
  "narrative_shift": true/false,
  "event_type": "policy | war | earnings | macro"
}
```

---

## 3.3 影响机制（核心逻辑）

### 1. 信号调节

```python
buy_score *= (1 - confidence * 0.3)
sell_score *= (1 + confidence * 0.3)
```

---

### 2. 仓位调节

```python
max_position *= 0.7  # high risk
```

---

### 3. 状态干预

```python
if event_type == "black_swan":
    force_state = PANIC
```

# 四、Event Layer（事件系统）

## 4.1 数据来源

- 新闻API（可扩展）
- 金融终端接口（AKShare / Baostock / 其他数据源）
- 自定义数据源（未来扩展）

⚠️ 注意：系统支持多数据源，不绑定单一API

---

## 4.2 Event数据结构

```python
Event:
  type: str
  sentiment: str
  impact_level: int
  scope: str
  duration: str
```

---

## 4.3 作用机制

| 作用 | 描述 |
|------|------|
| 调整仓位 | 降低风险 |
| 调整信号 | 抑制BUY |
| 触发极端模式 | PANIC |
