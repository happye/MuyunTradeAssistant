# v0.8.0 迭代规划 — 详细设计规格

> 版本：v0.8.0 | 创建：2026-05-05
> 基于：v0.7.3-stable (tag: v0.7.3-stable, branch: v0.7.3-stable-backup)

---

# 一、升级目标

v0.7.x 已具备五层架构 + 行为约束 + 可回测可解释，但存在核心缺陷：

- ❌ 无选股能力（Scanner）
- ❌ 无信息理解能力（新闻/叙事）
- ❌ 无动态市场认知（事件驱动）

v0.8 的本质：从"看K线" → "理解市场"，从"规则执行" → "信息驱动"

**AI只负责**：信息理解、情绪判断、事件解析
**AI不负责**：决策输出、交易执行

# 二、分阶段实施计划

## Phase 1：AI Modifier Layer（核心，最高优先级）

### 2.1.1 目标
在 Decision Layer → Strategy Layer 之间插入 AI Modifier，用 AI 分析新闻/情绪，调节信号和仓位。

### 2.1.2 新增文件
```
src/core/ai_modifier.py      # AI调节层主逻辑
src/data/news_client.py      # 新闻抓取客户端
configs/settings.yaml         # 新增 ai 配置节
```

### 2.1.3 数据源验证结果

| 数据源 | 接口 | 能力 | 速度 | 结论 |
|--------|------|------|------|------|
| AKShare | `stock_news_em(symbol)` | 个股新闻10条，含标题+内容+时间+来源 | ~2s/只 | ✅ 可用，个股级别 |
| AKShare | `stock_info_global_em()` | 全球财经快讯200条，含标题+摘要+时间 | ~2s | ✅ 可用，宏观级别 |
| AKShare | `stock_board_industry_name_em()` | 496个行业板块+涨跌+成分股 | ~3s | ✅ 可用，Scanner用 |
| AKShare | `stock_zh_a_spot_em()` | 全市场行情5000+只 | ~4min(58页) | ⚠️ 慢但可用，需缓存 |
| Baostock | `query_stock_basic()` | 5201只在上市A股列表 | ~2s | ✅ 可用，获取股票清单 |
| Baostock | `query_stock_industry()` | 证监会行业分类（逐只查询） | ~0.02s/只 | ✅ 可用 |
| Baostock | `query_history_k_data_plus()` | 个股K线（逐只查询） | ~0.02s/只 | ⚠️ 全市场需~100s |

### 2.1.4 AI API 配置

```yaml
# configs/settings.yaml 新增
ai:
  enabled: true
  provider: "deepseek"       # deepseek / kimi
  deepseek:
    api_key: ""              # 用户手动填写
    base_url: "https://api.deepseek.com"
    model: "deepseek-v4-flash"    # 默认用flash（快+便宜）
    model_pro: "deepseek-v4-pro"  # 深度分析时用pro
  kimi:
    api_key: ""              # 用户手动填写
    base_url: "https://api.moonshot.ai/v1"
    model: "moonshot-v1-auto"
    model_pro: "kimi-k2.6"        # 深度分析时用
  modifier:
    sentiment_weight: 0.3    # 情绪调节权重（buy_score *= 1 - confidence * 0.3）
    risk_position_cap: 0.7   # 高风险时仓位上限打7折
    max_news_per_stock: 10   # 每只股票最多抓取新闻条数
    cache_ttl: 3600          # 新闻缓存1小时
```

### 2.1.5 AI Modifier 输出结构

```json
{
  "sentiment": "bullish | bearish | neutral",
  "confidence": 0.0~1.0,
  "risk_level": "low | medium | high",
  "narrative_shift": true/false,
  "event_type": "policy | war | earnings | macro | none",
  "summary": "一句话摘要",
  "key_events": ["事件1", "事件2"]
}
```

### 2.1.6 影响机制（三层调节）

| 调节层 | 逻辑 | 可配置 |
|--------|------|--------|
| 信号调节 | `buy_score *= (1 - confidence × sentiment_weight)` | sentiment_weight |
| 仓位调节 | 高风险→`max_position *= risk_position_cap` | risk_position_cap |
| 状态干预 | `event_type == "black_swan"` → force PANIC | 硬编码 |

### 2.1.7 五层架构更新

```
Signal Layer → Decision Layer → AI Modifier Layer(新) → Strategy Layer → Execution Layer
```

Orchestrator.analyze() 流程更新：
1. SkillEngine → SkillSignal[]（不变）
2. DecisionEngine → DecisionResult（不变）
3. **AI Modifier → AIModifierResult（新增）**：AI分析新闻+调节信号
4. StrategyLayer → StrategyDecision（输入加入AI调节）
5. ExecutionLayer → ExecutionEvaluation（不变）

### 2.1.8 新闻抓取策略

```
用户分析 000001
  ├── 1. 个股新闻: stock_news_em(symbol='000001') → 10条
  ├── 2. 宏观快讯: stock_info_global_em() → 最新10条(缓存1小时)
  └── 3. AI分析: 拼接新闻文本 → DeepSeek API → AIModifierResult
```

**缓存机制**：宏观快讯缓存1小时，个股新闻缓存同会话（同一股票只抓一次）

### 2.1.9 CLI 变更

新增参数：
- `--ai` / `--no-ai`：启用/禁用AI调节（默认启用）
- `--ai-provider deepseek/kimi`：临时切换AI提供商

输出变更：分析结果新增"AI情绪"行：
```
🤖 AI情绪: bearish (confidence: 0.72) | 事件: earnings | 买入信号下调12%
```

## Phase 2：Scanner Layer（全市场扫描）

### 2.2.1 目标
全市场技术面扫描，输出候选股票池。

### 2.2.2 新增文件
```
src/core/scanner.py          # 扫描引擎
src/data/market_snapshot.py  # 全市场快照（缓存）
```

### 2.2.3 数据获取策略

**方案：AKShare stock_zh_a_spot_em() + 本地缓存**

- 一次性获取全市场行情（~4分钟），缓存到本地JSON
- 缓存有效期：盘中5分钟，盘后全天有效
- 基于快照数据做初筛（均线/量比/涨跌幅等），避免逐只查询Baostock
- 初筛后再对候选股逐只深度分析（走现有Orchestrator流程）

### 2.2.4 扫描规则（YAML声明式）

```yaml
# configs/scan_rules.yaml
rules:
  - name: "均线多头初现"
    description: "MA20 > MA60 且放量突破"
    filters:
      - field: "change_pct"
        op: ">"
        value: 0
      - field: "volume_ratio"  # 量比 = 当日成交额/20日均额
        op: ">"
        value: 1.5
    score: 60

  - name: "超跌反弹"
    description: "60日跌幅>20% 但当日放量反弹"
    filters:
      - field: "low_60d_drop_pct"  # 距60日高点的跌幅
        op: ">"
        value: 20
      - field: "change_pct"
        op: ">"
        value: 3
      - field: "volume_ratio"
        op: ">"
        value: 2.0
    score: 50
```

**扫描规则说明**：就是用技术面条件（均线、量比、涨跌幅、换手率等）从全市场5000+只股票中筛选出符合条件的候选池。类似"选股器"的概念。规则写在YAML中，用户可以自定义。

### 2.2.5 CLI 变更

```bash
python -m src.cli.main --scan                  # 全市场扫描（使用缓存快照）
python -m src.cli.main --scan --refresh         # 强制刷新快照
python -m src.cli.main --scan --sector 半导体    # 按行业扫描
```

## Phase 3：Event Layer（事件驱动）

### 2.3.1 目标
自动检测重大市场事件，触发预警和策略调整。

### 2.3.2 新增文件
```
src/core/event_layer.py      # 事件引擎
src/data/event_client.py     # 事件数据源
```

### 2.3.3 Event 数据结构

```python
class MarketEvent:
    type: str           # policy / war / earnings / macro / black_swan
    sentiment: str      # bullish / bearish / neutral
    impact_level: int   # 1-5 (5=黑天鹅)
    scope: str          # market / sector / stock
    duration: str       # short / medium / long
    source: str         # 新闻标题/摘要
    timestamp: datetime
```

### 2.3.4 事件检测逻辑

```
定时/触发式扫描:
  ├── 宏观快讯 (stock_info_global_em)
  │   └── 关键词匹配 + AI分类 → MarketEvent
  ├── 个股新闻 (stock_news_em)
  │   └── 持仓股新闻 → AI判断是否影响持仓
  └── 自定义规则
      └── 如：单日跌>5%、行业集体暴跌等 → 自动触发
```

### 2.3.5 作用机制

| 事件类型 | 作用 |
|----------|------|
| black_swan | 强制PANIC状态 |
| policy(利好) | 提升BUY信号权重 |
| policy(利空) | 压制BUY信号 |
| war | 降低仓位上限 |
| earnings(超预期) | 短期情绪利好 |
| macro | 调整整体风险偏好 |

## Phase 4：Ranking Layer（评分排序）

### 2.4.1 目标
对扫描结果进行多维度综合评分排序。

### 2.4.2 评分维度

| 维度 | 权重 | 数据来源 |
|------|------|----------|
| 技术面 | 40% | 原系统 SkillEngine |
| AI情绪 | 20% | AI Modifier |
| 流动性 | 20% | 成交额/换手率 |
| 波动性 | 20% | 历史波动率 |

输出：0-100分，按分排序

## Phase 5：Chat Agent Mode（对话模式）

### 2.5.1 目标
自然语言交互式选股与查询。

### 2.5.2 交互方式

在当前CLI中新增 `chat` 子命令，进入对话REPL循环：

```bash

  找到 175 只半导体相关股票，按技术面评分排序：

  2. ...

  [完整分析报告]
```

### 2.5.3 AI解析 → Tool调用

用户自然语言 → DeepSeek/Kimi API → function calling → 调用系统内部分析工具

工具列表：
- `search_stocks_by_sector(sector)` — 按行业搜索
- `analyze_stock(code)` — 分析单只股票
- `scan_market()` — 全市场扫描
- `get_portfolio()` — 查看持仓
- `get_news(code)` — 获取新闻
