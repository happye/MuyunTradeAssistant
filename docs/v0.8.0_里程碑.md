## Phase 1：AI Modifier Layer ✅

### 交付内容

| 文件 | 说明 |
|------|------|
| `src/core/ai_modifier.py` | AI调节层核心，DeepSeek/Kimi双提供商，三层调节 |
| `src/data/news_client.py` | 新闻数据客户端，个股新闻+宏观快讯+缓存 |
| `src/data/models.py` | 新增 AIModifierResult 模型（12字段） |
| `src/core/orchestrator.py` | 六层架构集成，analyze返回5元组 |
| `src/cli/main.py` | --no-ai/--ai-provider参数，AI情绪行展示 |
| `configs/settings.yaml` | ai配置节（双提供商+modifier参数） |

### 三层调节机制

1. **信号调节**：`buy_score *= (1 - confidence × sentiment_weight)`，看空时削弱买入信号
2. **仓位调节**：高风险时 `position_ratio *= risk_position_cap`，限制仓位上限
3. **状态干预**：黑天鹅事件 → 强制 PANIC 状态

## Phase 2：Scanner Layer ⬜

### 目标
全市场技术面扫描，输出候选股票池

### 核心设计
- AKShare `stock_zh_a_spot_em()` 获取全市场行情（~4min），本地缓存
- YAML声明式扫描规则（均线/量比/涨跌幅/换手率等条件）
- 初筛后对候选股走现有Orchestrator深度分析

### 待开发文件
```
src/core/scanner.py           # 扫描引擎
src/data/market_snapshot.py   # 全市场快照（缓存）
configs/scan_rules.yaml       # 扫描规则配置
```

### CLI
```bash
--scan              # 全市场扫描
--scan --refresh    # 强制刷新快照
--scan --sector 半导体  # 按行业扫描
```

### 数据源约束
- `stock_zh_a_spot_em()` 全市场~4min，需缓存
- `stock_board_industry_name_em()` 496个行业板块~3s
- ETF不在A股行情API中，需专用接口
