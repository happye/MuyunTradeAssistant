## Phase 1：AI Modifier Layer ✅

### 交付内容

| 文件 | 说明 |
|------|------|
| `src/core/ai_modifier.py` | AI调节层核心，DeepSeek/Kimi双提供商，三层调节 |
| `src/data/news_client.py` | 新闻数据客户端，个股新闻+宏观快讯+缓存 |
| `src/data/models.py` | 新增 AIModifierResult 模型（12字段） |
| `src/core/orchestrator.py` | 六层架构集成，analyze返回5元组 |
| `src/cli/main.py` | --no-ai/--ai-provider参数，AI情绪行展示 |
| `configs/settings.yaml` | ai配置节（双提供商+modifier参数） |

### 三层调节机制

1. **信号调节**：`buy_score *= (1 - confidence × sentiment_weight)`，看空时削弱买入信号
2. **仓位调节**：高风险时 `position_ratio *= risk_position_cap`，限制仓位上限
3. **状态干预**：黑天鹅事件 → 强制 PANIC 状态

## Phase 2：Scanner Layer ✅

### 交付内容

| 文件 | 说明 |
|------|------|
| `src/scanner/market_cache.py` | 全市场行情缓存（A股/ETF/行业板块，盘中5min/盘后长缓存） |
| `src/scanner/scanner_filter.py` | 声明式过滤器（17字段/11操作符，field/op/value三元组） |
| `src/scanner/scanner_engine.py` | Scanner引擎（quick_scan+deep_analyze两步走模式） |
| `src/scanner/scan_rules.yaml` | 5套默认扫描规则（放量突破/缩量回调/强势动量/低估值/超跌反弹） |
| `src/data/models.py` | 新增 ScanCandidate 模型 |
| `src/cli/main.py` | scan_market()+--scan/--scan-deep/--scan-industry等参数 |
| `start.py` | 交互模式新增scan market/industries命令 |
| `configs/settings.yaml` | 新增scanner配置节 |

### 两步走模式
1. **quick_scan()**: 快速初筛 → 展示候选池表格（缓存命中时秒级）
2. **用户选择**: 输入代码列表 / all全选 / q跳过
3. **deep_analyze()**: 逐只Orchestrator六层深度分析（每只~5秒）

### 自动排除规则
- ST/*ST股票（名称含ST）
- 停牌股（成交量=0）
- 北交所（8开头）
- 退市整理期（名称含退）
- 已持仓股票（可选，auto_exclude_holdings配置）

### 验证结果
- ✅ MarketCache: 5849只A股获取成功(240秒)，缓存命中秒级
- ✅ ScannerFilter: 5套规则全部校验通过
- ✅ ScannerEngine导入+规则加载正常
- ✅ CLI参数和交互命令语法检查通过### CLI
```bash
--scan              # 全市场扫描
--scan --refresh    # 强制刷新快照
--scan --sector 半导体  # 按行业扫描
```

### 数据源约束
- `stock_zh_a_spot_em()` 全市场~4min，需缓存
- `stock_board_industry_name_em()` 496个行业板块~3s
- ETF不在A股行情API中，需专用接口
