## Phase 2：分层回测模式 + 中间决策日志 ✅

### 已完成

1. 三层回测模式已可运行：`decision_only`、`decision_strategy`、`decision_strategy_execution`。
2. CLI 已支持 `--layer-mode` 切换。
3. 回测结果已记录 `diagnostics.daily_decisions` 与 `diagnostics.execution_logs`。
4. 导出表已优先使用真实日志而不是仅靠事后字符串推断。
5. 已支持 `--export-layer-comparison-json` 单次导出三层对照 JSON。
6. 已实现逐日 `merged_timeline`：三层 `daily_decisions` + `execution_logs` 按信号日期对齐，形成统一逐日对照视图。
7. 已实现层间分歧自动分类：`none` / `strategy_modified` / `execution_blocked` / `strategy_and_execution`。
8. 已支持 `--export-layer-comparison-txt` 导出人类可读的三层对照分析报告。
9. 对照文本报告包含：层级汇总表、层间差异、分析提示、逐日分歧统计、分歧逐日明细。

### 已落地能力

1. 单次命令即可产出三层对照导出（JSON + TXT），并能稳定区分信号层、策略层、执行层责任。
2. merged timeline 提供逐日三层数据对齐，自动标记层间分歧类型与发生频率。
3. 分歧明细可精确定位"哪天、哪层、如何修改"（如策略层将 ADD 改为 HOLD_POSITION）。
4. 对照 JSON 的 `merged_timeline.divergence_summary` 可直接用于 AI 归因分析。

注：基础文本化对照报告已具备，当前缺的是更细粒度的 merged timeline 与更正式的 analyzer 结构。

## Phase 3：偏差检查与研究验证基线 🟡

### 已完成

1. 已新增 `src/core/backtest_validator.py`，形成独立验证模块。
2. CLI 已支持 `--export-validation-json` / `--export-validation-txt`。
3. 已支持 lookahead 时序检查：验证 `signal_date < execution_date`。
4. 已支持样本内 / 样本外拆分和 walk-forward 窗口验证。

### 当前缺口

1. 还没有回测与实时/准实时一致性检查。
2. 还没有多标的批量验证模板。
3. 还没有按趋势/震荡/极端行情分桶的验证报告。
