## Phase 1：回测诊断导出层 ✅

### 已交付

| 文件 | 说明 |
|------|------|
| `src/core/backtest_reporter.py` | 回测结果结构化导出，支持 JSON/TXT |
| `src/cli/main.py` | 新增 `--export-analysis-json` / `--export-analysis-txt` / `--layer-mode` |
| `src/data/models.py` | `BacktestResult` 增加 `layer_mode` 与 `diagnostics` |

### 已落地能力

1. 回测结果可导出为 AI 可消费的结构化 payload。
2. 导出内容已覆盖 `summary`、`trades`、`daily_snapshots`、`layer_breakdown`、`action_source_table`、`hold_break_table`、`diagnostics`。
3. 动作与持仓破坏表已增加层级归因：`trigger_layer` / `broken_layer`。
4. 持久化策略已明确：仅在显式传入导出路径时写文件，不自动归档到固定目录。

### 已验证样本

- `tests/layer_decision_only.json`
- `tests/layer_decision_strategy.json`
- `tests/layer_full.json`

## Phase 2：分层回测模式 + 中间决策日志 🟡

### 已完成

1. 三层回测模式已可运行：`decision_only`、`decision_strategy`、`decision_strategy_execution`。
2. CLI 已支持 `--layer-mode` 切换。
3. 回测结果已记录 `diagnostics.daily_decisions` 与 `diagnostics.execution_logs`。
4. 导出表已优先使用真实日志而不是仅靠事后字符串推断。

### 当前缺口

1. 还没有“一次命令自动产出三层对照结果”的合并导出。
2. 还没有正式的多层对照分析器或统一 comparison payload。
