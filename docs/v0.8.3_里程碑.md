## Phase C：买点/卖点精确触发 📋

### 交付内容
| 文件 | 说明 |
|------|------|
| `src/core/entry_exit/calculator.py` | EntryExitCalculator 主计算器 |
| `src/core/entry_exit/entry_rules.py` | 买点规则（突破/回调/北向确认） |
| `src/core/entry_exit/exit_rules.py` | 卖点规则（移动止损/趋势破坏/止盈/资金流出） |
| `src/core/entry_exit/price_level.py` | 价格计算（ATR/Chandelier/MA） |
| `src/core/entry_exit/config.yaml` | 买卖点参数配置 |
| `src/core/orchestrator.py` | 修改：接入买卖点优先级覆盖 |
| `tests/test_entry_exit/` | 测试套件 |

### 验收标准
| 指标 | 目标 |
|------|------|
| 胜率 | 相比无买卖点提升 5%+ |
| 盈亏比 | 提升 15%+ |
| 最大回撤 | 降低 10%+ |
| 误触发率 | < 10% |
| 错过率 | < 15% |

### 参考方法论
- Chandelier Exit (Le Beau)
- ATR 止损 (Wilder)
- 海龟交易法则 (Dennis/Eckhardt)
- CANSLIM (O'Neil)
- SEPA (Minervini)
- Freqtrade Entry/Exit 模型
- Backtrader 事件驱动模型
