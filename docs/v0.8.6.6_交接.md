## 二、最重要的诚实结论（下个会话必读）

### 2.1 网络问题的根因是代理，不是代码

用户开着 clash（系统代理模式），金融 API（新浪/东财）的请求被 clash 拦截/转发，返回状态码 456 + HTML（不是 JSON）。

**治本**：`start.py` 和 `src/cli/main.py` 启动时设 `NO_PROXY=*`，强制 requests/urllib3 对所有域名直连，绕过 clash 系统代理。

**局限**：如果 clash 用 TUN 模式（网络层劫持所有流量），`NO_PROXY` 无效——只能关代理或配 clash 分流规则（金融域名走直连）。用户是 clash 系统代理模式，`NO_PROXY=*` 有效。

### 2.2 新浪全市场源是间歇性失效的

即使代理问题解决，新浪全市场快照（`stock_zh_a_spot_em` / `getHQNodeData`）仍**偶发返回空**（几小时一变）。代码已加重试3次（间隔1.5秒）+ efinance 备用源兜底，不再锁死/刷屏。

**影响**：`bz scan` 无参数 / `bz scan --allrules` 偶发"无候选"，重试即可。`bz <代码>` / `l <代码>` / `bz scan <主题词>` 走 Baostock/法C，不受影响。

## 五、bz scan 完整用法（用户最常问）

| 命令 | 干什么 |
|---|---|
| `bz scan <主题词>` | 双通道选股（法C+全市场行业成分股）→ 笨总评分 |
| `bz scan`（无参数） | 全市场技术初筛（healthy_pullback规则）→ 笨总评分Top10 |
| `bz scan --allrules` | **四规则全跑**（healthy/steady/shrink/value 各Top5合并去重）→ 笨总评分Top10 |
| `bz scan --rule <规则名>` | 指定单规则 |
| `bz <代码>` | 单股笨总6维评分（基本面质量） |
| `l <代码>` | **实时择时**（七层分析，BUY/SELL/HOLD+Weinstein阶段）⭐ |
| `pos add <代码>` | 建仓+自动定mode（A级气宗/B级剑宗） |

**核心工作流**：`bz scan`选股(基本面) → `bz <代码>`细看6维 → **`l <代码>`看择时买点** → `pos add`建仓 → `pos plan`/`l`持有监控。

**关键认知**：`bz`评"公司好不好"(基本面)，`l`评"现在该不该动"(择时)。A级不代表该买，必须配合`l`的BUY信号。

## 六、4条选股规则（v0.8.6.5 修复平收股bug后）

| 规则 | 过滤条件 | 适用市况 |
|---|---|---|
| healthy_pullback（默认） | 涨跌幅-3%~-0.1% + 缩量 + 换手1-10% + 振幅<6% + 成交额>1亿 | 牛市找回调买点 |
| steady_advance | 涨跌幅0.1%~5% + 量比1.1-3 + 换手1-12% + 振幅<7% | 蓄势期找突破 |
| shrink_pullback | 涨跌幅-5%~-0.1% + 换手0.5-5% + 量比<0.8 + 振幅<5% | 震荡市找洗盘企稳 |
| value_pick | PE 1-20 + PB 0.1-2 + 价格>3 + 换手>0.5% | 价值投资，不挑市况 |

**已修复**：change_pct 区间排除0（平收股=主力控盘做收盘价，非回调/上涨，不该入选）。

## 九、踩坑警示（本会话新增）

- **代理是网络问题根因**：用户开 clash，金融API被拦截返回456。`NO_PROXY=*` 治本。排查网络问题先查代理
  - 注（2026-08-23 ISS-056 收尾核对）：456/失败有**两层原因并存**——代理拦截（本条，NO_PROXY=* 治本）与东财 em 端点自身反爬（与代理无关，ISS-040 换源治本、em 系接口已弃用改 THS，见 docs/数据接口台账.md）。排查时先分清是哪一层
- **测试环境≠实跑环境**：测试脚本清了代理env但没设NO_PROXY，导致"测试通过但实跑挂"的假通过。测试必须模拟实跑环境（设NO_PROXY=*）
- **闭区间边界含0是隐蔽bug**：`change_pct between[-3,0]` 把平收股(涨跌幅0)误纳入"回调"。见 ISS-048 + 记忆 feedback_closed_interval_boundary
- **baostock库直接print不走logging**：login success/you don't login 是库print的，无法用logger静音，曾试重定向stdout但改过头已回退，保留正常输出
- **新浪全市场间歇性失效**：偶发返回空，代码已重试3次+efinance兜底，不锁死不刷屏
- **不要用大盘级信号解个股级问题**：MarketState闸门回退教训，见记忆 feedback_overfix_rabbit_hole
