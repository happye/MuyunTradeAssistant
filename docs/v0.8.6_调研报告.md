## 第 I 部分：笨总策略提炼（从 13 份资料中提取的最小可执行骨架）

我把 10 篇教学 + 3 份课件浓缩成 **6 大核心模块** + **1 个量化打分公式**。所有引用都来自笨总原文。

### 1. 选股流程 5 步（教学 1 + 基本框架课件）

```
拐点事件识别 → 高景气行业筛选 → 板块/细分定位 → 个股立体筛选 → 风险评估
```

每步的判定标准：

**步骤 1：4 类拐点事件**
- 重大科技突破（如 23 年 ChatGPT）
- 政治经济突发（如 19 年芯片制裁）
- 全球供应能力萎缩（比例要大）
- 海外成功企业的"照镜子"效应（如 AppLovin → A 股 AI 广告）

**步骤 2：3 标准筛选高景气行业**
1. 政策与资金支持
2. 巨大市场空间（未来"全民使用"）
3. 商业化已到临界点（已有企业开始规模化赚钱）

**步骤 3：上下游反直觉原则**
- 新兴科技 → 死磕**最上游 / 卡脖子环节**（卖铲子的人先富起来，如 AI 浪潮中的 GPU）
- 传统行业反转 → 抱紧**最下游龙头**（议价权在下游品牌）

**步骤 4：4 大个股参数**
- 业务纯度（主营占比越高越好）
- 历史价格位置（近一年涨幅 < 150% / 三年最低价 200% 以内 / 历史 30% 水位以下）
- 细分行业龙头地位
- 市场辨识度（"提到 X 第一反应是它"）

**步骤 5：两类风险评估**
- 原地坐牢（不涨不跌）：估值偏低 / 大股东减持惯犯 / 业绩兑现遥遥
- 暴跌暴雷：审计保留意见 / 安全事故 / 制裁 / 友商颠覆性突破

### 2. 现象级事件四要素（教学 3，最核心）

> "面对突发新闻，必须逐条审视这四点。**真实性是一票否决权**。"

| 要素 | 评估标准 | 一票否决 |
|------|---------|---------|
| 真实性 | 必须交叉验证，不能只看一个来源 | ✅ 假的全部作废 |
| 传播性 | 出圈，全民讨论 | — |
| 规模性 | 行业体量足够大（卫生巾事件就是规模性不够而失败） | — |
| 时效性 | 第一次最有价值，重复消息市场反应递减 | — |

国内政策事件额外 5 要素：级别（部委/国务院 > 顶层规划 > 地方）、落地周期、数字规模、持续性、覆盖群体。

### 3. 笨总打分模型（教学 2 + 打分表 .xlsx）

直接量化的核心公式（来源 `笨总课件/笨总选股打分表.xlsx`）：

```
总分 = (
    行业景气度 × 20%
  + 业务纯度 × 40%   ← 权重最大
  + 历史估值位置 × 25%
  + 细分行业龙头 × 15%
  + 市场辨识度 × 20%
  + 个股风险值 × (-20%)   ← 扣分项
) × 流动性系数

流动性系数：
  0.8 万亿以下 → ×0.8
  1.5 万亿以上 → ×1.2
  其他       → ×1.0
```

**大前提（必须先满足）**：行业景气度判断为前置 — **没有高景气行业判断，整个打分模型不能用**（教学 2 反面案例：中免 0 景气度 + 其他全 100 = 仍然 0 分；模型套用的是乘号关系）。

### 4. 剑宗气宗双模式（教学 5）

| 模式 | 适用 | 风险/收益特征 | 占比 |
|------|------|--------------|------|
| **气宗（长期格局）** | 1→10 产业化突破，业绩持续兑现 | 慢但稳，渗透率突破 30% 前要拿稳 | **70%** |
| **剑宗（一波流）** | 0→1 技术突破 / 突发事件驱动 | 快但烈，破线必走 | **30%** |

**纪律红线**：
- 气宗标的两个月暴涨 5-10 倍 → 也必须考虑止盈
- 剑宗标的高位放量跌破趋势线 → 立即止盈

### 5. 高位止盈 3 维度（教学 8）

**宏观维度（市场大顶，"或"关系，触发任一即清仓）**：
1. 官方"发金牌"密集 + 抽流动性政策
2. 储蓄搬家 > 30% / 单日成交 > 10 万亿
3. "非互联网用户"入场（你奶奶问股票代码）
4. 历史级产业兑现（卡脖子全面突破 → 反而是顶）

**板块维度**：
- 渗透率 30% 魔咒（成长股估值切换为价值股）
- 新赛道虹吸（更性感的风口起来时旧风口熄火）
- 旗手滞涨（板块龙头 = 旗手，它涨不动 = 板块见顶）

**个股维度**：
- 单日换手率 > 40% → "死亡换手"
- 缩量加速上涨 → "最后的疯狂"
- 偏概念票 → 利好兑现即利空
- "一波流三倍定律"（涨 3 倍后破 5 日线即清）
- 实控人减持 / 股东人数从 5 万爆增到 15 万

### 6. 自主可控 vs 遥遥领先 双向映射（教学 9）

> 公式：东大的自主可控 = 西方的遥遥领先；东大的遥遥领先 = 西方的自主可控

跨市场寻宝：
- 西方遥遥领先（HBM / 先进制程 / AI 应用）→ A 股自主可控映射
- 东大遥遥领先（稀土 / 锑 / 镓 / 激光雷达）→ 美股自主可控映射（如美股 MP 材料、美股锑、AEVA 激光雷达）

**关键筛选**：必须 "断档领先 + 不过剩 + 未来持续爆发"。光伏/家电/新能源车已经过剩出局，稀土+小金属是当前核心。

## 第 II 部分：与当前工具架构的对齐分析

把笨总 6 大模块映射到当前七层架构，看哪些**已有可复用**，哪些**完全缺失要新增**：

| 笨总模块 | 当前工具状态 | 可复用 | 缺失 |
|---------|------------|--------|------|
| **拐点事件识别** | Event Layer 已有"关键词匹配 + AI 分类 + 9 条规则"，但**无 4 要素一票否决判定** | 基础架构在 | 真实性交叉验证 / 规模性量化 / 传播性识别 |
| **高景气行业筛选** | Scanner 有 4 条规则但都是技术面，**无"政策/市场空间/商业化临界点"判定** | 数据加载链路 | 行业景气度量化指标 |
| **上下游反直觉** | **完全无** | — | 全部新增 |
| **4 大个股参数** | 业务纯度无 / 历史位置部分有（StateMachine.年线判断）/ 龙头地位无 / 辨识度无 | StockData 字段 | 业务纯度 + 龙头识别 + 辨识度 |
| **现象级事件四要素** | AI Modifier 读新闻但**无四要素结构化判定** | AI 调用框架 | 真实性 / 传播性 / 规模性 / 时效性 4 维度判定 |
| **打分模型** | 七层架构有信号投票（DecisionEngine），但**与笨总 6 维度公式完全不一致** | 投票框架 | 完全替换 — 笨总 6 维 vs 当前 base/regulator/action 三类 |
| **剑宗气宗** | TradePlan + max_hold_days 接近"气宗"，但**无"剑宗"短线模式** | TradePlan 骨架 | 剑宗模式 + 30/70 仓位分配 |
| **高位止盈 3 维度** | EntryExit 有 Chandelier / take_profit_trim 但只在个股维度，**无宏观/板块维度信号** | 个股止盈 | 宏观清仓信号 + 板块清仓信号 |
| **自主可控 vs 遥遥领先** | **完全无** | — | 全部新增（需要跨市场数据） |

### 关键判断：当前工具是否需要"推倒重来"？

**不需要**。理由：

1. **七层架构本身没错**，错在"信号触发依据"——把 MA/RSI/MACD 这种技术指标当首要信号，而不是把"行业景气度 + 拐点事件"当首要信号
2. **TradePlan 子系统正好是笨总策略需要的容器**——thesis / when_sell_invalidate / fundamental_outlook 完美对应"为什么买/失效条件/前景"
3. **scan_market + 深度分析两步走**正好是"高景气筛选 → 个股打分"的载体
4. **缺的不是底层引擎，是顶层的"笨总评分器" + "事件四要素判定器"** — 把它们插到现有七层之上即可

## 第 III 部分：融合架构方案（笨总为主 + 当前工具为骨架）

### 架构图（v0.8.6 新七层 + 笨总评分器）

```
[Layer 0: 数据层]
  └─ Baostock + 新浪 + AKShare（不变）
  └─ 新增：财务数据接入（业务纯度需要） + 新闻面（事件四要素需要）

[Layer 1: 笨总现象级事件识别器] ← 新增，最高优先级
  └─ 4 要素结构化判定（真实性/传播性/规模性/时效性）
  └─ AI + 规则 + RAG 三路并行（真实性靠交叉验证）
  └─ 输出：BenzhongEvent {type, confidence, scope}

[Layer 2: 高景气行业判定器] ← 新增
  └─ 全市场分行业聚合：政策/资金流入/商业化阶段
  └─ 输出 RANKED_INDUSTRIES

[Layer 3: Signal/Decision/Event/AI] ← 当前 4 层保留
  └─ 但 base 信号权重降低，让笨总评分器主导

[Layer 4: 笨总评分器] ← 新增（替代 DecisionEngine 的部分逻辑）
  └─ 6 维打分公式（教学 2 + 打分表）
  └─ 流动性系数（动态读全市场成交额）
  └─ 输出 Top-N 候选

[Layer 5: TradePlan 子系统] ← v0.8.5 已有，扩展
  └─ 新增 mode 字段：剑宗 / 气宗
  └─ 剑宗 → max_hold_days=30 / 破线即走
  └─ 气宗 → max_hold_days=180 / 渗透率 30% 警告

[Layer 6: 高位止盈 3 维度监控] ← 新增（PlanGuard 升级）
  └─ 宏观信号：成交额突破/储蓄搬家/官方发金牌（每日全市场）
  └─ 板块信号：渗透率统计/旗手滞涨/虹吸
  └─ 个股信号：换手率 40% / 缩量加速 / 实控人减持

[Layer 7: Strategy / Execution] ← 当前层保留
  └─ Strategy 加 30/70 剑宗气宗仓位分配
```
