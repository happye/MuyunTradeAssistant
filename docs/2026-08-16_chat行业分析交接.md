## 一、功能全景（chat 行业分析）

**入口**：chat 模式问任何行业/板块/产业链问题；REPL `chains` 命令管理图谱。

**两级路由（数据待遇对等）**：
1. 图谱命中（手写 6 条 `configs/industry_chains.yaml` + AI 自举 `configs/industry_chains_auto.yaml`）-> 环节结构 + 数据绑定（无绑定时自动走关键词映射兜底）+ 自举链附动态板块节
2. 未命中 -> 通用引擎：THS 板块解析（90行业+375概念，精确>包含>LCS 三级匹配）+ 成分股市值Top8 + 板块温度（涨跌中位数/涨跌家数/Top8 PE中位数）+ 主营抽样5只 + 商品锚映射（13链）+ 需求兜底 + 宏观 + 分析指引

**图谱自举**：AI 完成非图谱行业分析后调 `save_chain_graph` 沉淀结构 -> 下次直接走图谱路径。防幻觉（只写工具结果出现过的代码）、防冗余（同名覆盖）、防过时（created_at + >30天提示重新分析覆盖）、手写优先、`chains rm` 可删。

**关键文件**：
| 文件 | 职责 |
|------|------|
| `src/data/industry_data.py` | 数据层全部：图谱加载/匹配/自举/商品映射/格式化/组装 |
| `src/chat/tools.py` | analyze_industry / get_main_business / save_chain_graph 工具 |

## 二、动态维护机制（用户重点关切）

| 风险 | 机制 |
|------|------|
| 图谱过时 | 自举图谱带 created_at，>30天报告头提示"重新分析覆盖"；重新分析+save 即刷新 |
| 冗余增长 | 同名覆盖不增条目；每条2-4KB，50行业≈200KB 无压力 |
| 能力衰减 | 全降级链：图谱缺->通用引擎；接口挂->[数据缺失]；THS封->板块缺失提示。每层挂了 AI 仍能基于剩余数据+框架作答并明说缺口 |
| 接口失效 | 台账登记+实测状态；THS 封禁观察点=行业板块解析持续"未匹配到" |
