## Phase 1：RAG基础设施 ✅

### 交付内容

| 文件 | 说明 |
|------|------|
| `src/rag/__init__.py` | RAG模块入口 |
| `src/rag/models.py` | RAGDocument/RetrievalResult/StrategyCategory/Quantifiability模型 |
| `src/rag/ingestion.py` | 策略文件摄入：65个txt→306个文档块，心流战法过滤 |
| `src/rag/embedding.py` | 双嵌入器：SentenceEmbedder(BGE)+TFIDFEmbedder(降级)，离线优先加载 |
| `src/rag/store.py` | 双向量存储：FAISSVectorStore(主力)+NumpyVectorStore(降级) |
| `src/rag/retrieval.py` | 混合检索：KeywordRetriever(BM25/jieba)+HybridRetriever(RRF融合) |
| `src/rag/context.py` | 上下文构建：chat/event/modifier三种格式化模板 |
| `src/rag/service.py` | RAGService统一入口+增量索引（文件指纹检测变化） |

### 核心参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| chunk_size | 500字 | 文档分块大小 |
| chunk_overlap | 50字 | 分块重叠 |
| default_top_k | 5 | 默认检索数量 |
| retrieval_method | hybrid | keyword/semantic/hybrid |
| hybrid_weights.keyword | 0.4 | 关键词检索权重 |
| hybrid_weights.semantic | 0.6 | 语义检索权重 |
| embedding.provider | sentence | sentence(BGE)/tfidf(降级) |
| embedding.model | BAAI/bge-small-zh-v1.5 | 中文嵌入模型(512维) |

### 技术要点

- **BGE中文模型**：bge-small-zh-v1.5，512维向量，33MB，查询前缀"为这个句子生成表示以检索相关文章："
- **HuggingFace离线模式**：模块级设置`HF_HUB_OFFLINE=1`+`HF_ENDPOINT=hf-mirror.com`，避免每次启动超时
- **增量索引**：保存fingerprint.json记录策略文件修改时间，文件变化自动重建索引
- **心流战法过滤**：摄入时检测心流战法内容并跳过（非技术策略）

## Phase 3：策略逻辑增强 ✅

### 1. 事件类型→策略知识映射（Event Layer）

```python
EVENT_RAG_QUERIES = {
    "policy": "政策变化应对策略 行业监管影响",
    "war": "地缘冲突 市场避险 黑天鹅应对",
    "earnings": "财报分析 业绩评估 估值调整",
    "macro": "宏观经济 市场周期 大盘环境",
    "black_swan": "黑天鹅事件 极端风险 危机应对 止损",
    "market_crash": "暴跌应对 止损策略 恐慌抛售",
}
```

### 2. AI Modifier智能搜索query

- 从新闻文本中提取事件关键词（政策/监管/降息/暴雷/暴跌等）
- 映射到对应的RAG搜索词（如"暴雷"→"风险事件 止损策略"）
- 限制搜索词长度，避免语义稀释

### 3. 增量索引机制

- 保存fingerprint.json记录每个策略文件的修改时间
- 初始化时加载缓存索引→检查文件变化→自动重建
- 支持force_rebuild强制重建
- 首次v0.8.1升级（无fingerprint.json）不会强制重建

## 架构定位

RAG在七层架构中的位置：

```
Data Layer
   ↓
Signal Layer（Skill Engine）
   ↓
Decision Layer（信号聚合器）
   ↓
Event Layer（v0.8.1 RAG增强）← 策略知识注入AI事件分类
   ↓
AI Modifier Layer（v0.8.1 RAG增强）← 策略知识注入AI新闻分析
   ↓
Strategy Layer
   ↓
Execution Layer
```

Chat Agent作为独立接入点，通过search_knowledge工具直接查询。

**重要原则**：RAG只提供参考信息，不参与交易决策链。BUY/SELL决策仍由Decision Layer→Strategy Layer→Execution Layer完成。
