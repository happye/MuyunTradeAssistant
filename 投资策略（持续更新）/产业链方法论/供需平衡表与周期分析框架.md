# 供需平衡表与周期分析框架

> 产业链方法论系列。适用场景：分析任何周期性行业（锂电、光伏、煤炭、黄金、猪肉、化工等）的供需格局与周期位置。

## 一、核心框架：量-价-库存-产能四要素

行业周期分析不预测价格，而是回答四个问题：

1. **量**：需求增速 vs 供给增速，谁更快？
   - 需求增速 > 供给增速 → 供需趋紧 → 价格中枢上移
   - 供给增速 > 需求增速 → 供需趋松 → 价格中枢下移
2. **价**：当前价格在历史区间什么分位？
   - 高分位 ≠ 见顶，低分位 ≠ 见底，但分位决定赔率（低位做空风险大，高位做多风险大）
3. **库存**：在累库还是去库？
   - 价格低位 + 持续去库 = 需求真实回暖信号
   - 价格低位 + 持续累库 = 过剩仍在恶化，勿抄底
   - 价格高位 + 累库 = 需求转弱预警
4. **产能**：在高成本产能出清，还是在扩产？
   - 行业亏损面扩大 → 高成本产能减产/停产 → 出清 → 供给收缩（周期底特征）
   - 行业暴利 → 扩产潮 → 2-3年后供给释放（周期顶特征）

## 二、周期四阶段模型

| 阶段 | 特征 | 股价位置 | 操作含义 |
|------|------|---------|---------|
| ① 过剩恶化 | 价格跌、库存累、全行业亏损 | 戴维斯双杀（PE×EPS齐跌）| 观望，等出清信号 |
| ② 出清筑底 | 高成本产能退出、价格企稳、库存见顶回落 | 股价领先基本面见底（预期先行）| 左侧观察窗，等右侧确认 |
| ③ 供需反转 | 需求超预期/供给收缩兑现、价格反转、去库加速 | 主升浪，盈利与估值双击 | 趋势确认后参与 |
| ④ 过热扩产 | 价格高位、全行业暴利、扩产公告满天飞 | 估值泡沫化，股价往往先于价格见顶 | 兑现期，勿恋战 |

**关键规律**：
- 股价底领先商品价格底约 1-2 个季度（股票交易预期）
- 商品价格顶时盈利最好、PE最低——**周期股低PE是卖出信号而非买入信号**（低PE出现在盈利顶）
- 商品价格底时盈利最差、PE畸高甚至亏损——**周期股高PE/亏损可能是买入区域**（盈利底）

## 三、产业链利润分配规律

价格周期决定链条利润往哪个环节迁移：

- **价格上行期**：利润向上游资源端集中（矿企利润弹性最大），下游承压（成本上升）
- **价格下行期**：利润向中下游制造端回流（电池/组件/整机毛利率修复），上游资源端利润收缩
- 判断某环节的投资价值，先问：当前价格方向下，利润正在流向哪个环节？

## 四、基差与仓单的解读（期货数据）

- **基差** = 现货价 − 期货价
  - 现货升水（基差为正）：现货紧张，近端供需偏紧
  - 现货贴水（基差为负）：现货过剩或仓单压力，市场对远期更乐观
- **仓单趋势**（免费可得的库存代理）
  - 持续累库 → 供给过剩或需求疲弱
  - 持续去库 → 供需收紧
  - 注意：仓单只是交割库库存，非全社会库存（全社会库存多为付费数据），只能看趋势方向

## 五、需求与供给的领先/滞后关系

- 终端需求（销量/装机）→ 中游排产（约1个月）→ 上游原材料价格（约1-2个季度）
- 供给端：扩产决策 → 投产 → 有效供给释放，通常 2-5 年（矿山>化工产能>制造业产线）
- 因此：**需求变化是快变量（月度可跟踪），供给变化是慢变量（年度级）**——这就是周期存在的原因

## 六、分析模板（回答行业问题时的检查清单）

1. 当前价格在什么区间分位？（带数据日期）
2. 供给端：哪些来源/厂商？成本曲线如何排序？有没有出清或扩产证据？
3. 需求端：终端增速如何？有没有结构性变化（渗透率、替代、新场景）？
4. 库存方向：累库还是去库？（仓单/显性库存代理）
5. 周期位置：处于四阶段模型的哪一段？证据是什么？
6. 上下游传导：当前利润集中在哪个环节？方向如何变化？
7. 数据缺口诚实声明：哪些关键数据拿不到？结论的置信度因此降多少？

## 七、常见错误

- 用静态低PE/低PB给周期股估值（盈利顶陷阱）
- 价格一跌就抄底（忽视供给释放周期未结束）
- 把短期波动当趋势反转（没有库存/供给证据）
- 只看供给不看需求，或反之（供需必须对照）
- 忽视政策变量（产能置换、长协、补贴、关税——尤其A股）
