# 锂电产业链全景图

> 产业链方法论系列。回答锂矿/碳酸锂相关问题时的事实底座：环节结构、成本曲线、利润分配、跟踪指标。

## 一、链条结构总览

```
上游资源                中游材料                下游制造/终端
├─ 锂辉石（澳/非/川西）  ├─ 锂盐加工（碳酸锂/氢氧化锂）  ├─ 电芯/电池（宁德/比亚迪…）
├─ 盐湖提锂（青藏）      ├─ 正极（LFP/三元）            ├─ 新能源整车
└─ 锂云母（江西）        ├─ 负极/隔膜/电解液            └─ 储能（第二曲线）
                        └─ 回收锂
```

## 二、上游三大来源与成本曲线

供给端必须分来源讨论，三类来源成本与弹性截然不同：

| 来源 | 成本位置 | 代表 | 特点 |
|------|---------|------|------|
| 盐湖提锂 | 最低 | 察尔汗（盐湖/藏格）、扎布耶 | 镁锂比决定提取难度；扩产受地理与环保约束，周期长 |
| 锂辉石 | 中等 | Greenbushes（天齐）、Bikita（中矿）、甲基卡（融捷）、李家沟（川能动） | 品位高工艺成熟；澳洲+非洲+川西三分；非洲矿有爬产与运输扰动 |
| 锂云母 | 最高 | 江西宜春（江特、永兴部分） | 品位低、渣处理成本高；价格下行期最先亏损减产，是"出清温度计" |
| 回收锂 | 随碳酸锂价格波动 | 各家电池回收厂 | 价格高时经济性好、放量；价格低时停产 |

**判断周期底的关键观察**：锂云母/回收产能是否大面积亏损停产（高成本出清）+ 盐湖/辉石龙头是否减产。

## 三、中游与下游要点

- **锂盐加工**：分"自有矿一体化"（天齐/赣锋/中矿，成本可控）与"外购矿加工"（纯加工费模式，价格下行期双杀）
- **正极**：磷酸铁锂占国内动力主流（渗透率约七成）；正极厂普遍"原材料价格传导"定价，碳酸锂涨跌基本顺价，赚加工费
- **负极/隔膜/电解液**：各自独立产能周期，与碳酸锂价格相关性低
- **电池**：集中度最高（宁德+比亚迪过半份额），议价能力最强；碳酸锂价格下行期电池环节毛利率修复最明显
- **整车**：终端需求源头；月度销量（乘联会）是最及时的需求跟踪数据
- **储能**：锂电第二需求曲线，对碳酸锂价格敏感（低价刺激储能项目经济性）

## 四、利润分配规律（核心分析框架）

- 碳酸锂**价格上行期**：利润集中上游矿端，"有矿"公司利润弹性最大；电池/整车承压
- 碳酸锂**价格下行期**：利润向电池/整车回流；矿端利润收缩，纯加工厂（外购矿）最先亏损
- 所以谈锂电投资必须先回答：**碳酸锂价格中枢往哪个方向走？利润正在流向哪个环节？**

## 五、历史周期复盘（定性）

- 2021-2022：新能源车渗透率陡峭爬坡，供给跟不上，碳酸锂从数万涨到约60万元/吨，矿股大牛市
- 2023-2024：扩产供给集中释放+需求增速降档，价格深跌约八成，全行业去库，矿股戴维斯双杀
- 教训：供给投产周期3-5年，2021年的暴利 -> 2023年的过剩；周期必然，只是时点难测
- 猪周期、光伏硅料周期与此同构：暴利→扩产→过剩→出清，读懂一个可类推其他

## 六、关键跟踪指标（免费数据可得性）

| 指标 | 免费可得性 | 用途 |
|------|-----------|------|
| 碳酸锂期货价格（广期所） | ✅ 期货日线/现货/基差 | 价格中枢与趋势 |
| 期货仓单 | ✅（交割库库存代理） | 库存方向（累库/去库） |
| 新能源车渗透率/销量 | ✅ 乘联会月度 | 终端需求增速 |
| 全社会用电量 | ✅ 月度 | 宏观需求底色 |
| 动力电池装机量 | ❌ 无免费接口（缺口） | 用销量+厂商排产新闻代理 |
| 储能装机量 | ❌ 无免费接口（缺口） | 用政策与招标新闻代理 |
| SMM周度产量/库存/开工率 | ❌ 付费墙 | 用仓单+公告代理 |
| 澳矿/非洲矿发运量 | ❌ 付费墙 | 用财报与新闻代理 |

## 七、回答锂电问题的检查清单

1. 碳酸锂价格现在多少？处于历史/近一年什么分位？（带日期）
2. 三大供给来源（盐湖/辉石/云母）各自的量价与成本状态？出清证据？
3. 需求端：新能源车销量/渗透率增速？储能进展？
4. 仓单在累库还是去库？
5. 周期位置：四阶段模型哪一段？什么证据？
6. 利润分配：价格方向决定利润流向上游还是下游--持仓公司在链条哪个环节、吃不吃得到本轮利润？
7. 数据缺口声明：装机量/SMM数据拿不到时必须明说
