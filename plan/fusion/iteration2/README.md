2026-09-26｜架构审查基线 `5b2e262` / v0.8.20｜**2026-09-27 更新：R0–R8 已实施**（账本 [EXECUTION_RECORD.md](EXECUTION_RECORD.md)；独立验收裁决 [R9_INDEPENDENT_REVIEW.md](R9_INDEPENDENT_REVIEW.md)——有条件通过，opt_in/default 不晋级）。下文设计与裁决原文保留不改写。

用户授权仍是架构、研究、规划和验收设计。本轮没有修改产品代码、配置、测试或持仓，没有执行新收益回测。交付报告中的 1121 tests 是实施方记录，本轮未重跑，不作为架构验收的替代证据。

## 1. 验收结论

**有条件接受第一轮工程交付；不接受“原始设计已全部验收通过”“融合投资能力已得到验证”的扩大解释。暂不支持将融合主决策晋级 opt_in/default。** 继续使用已交付的持仓事实分离、统一终态、工作台、证据记录与诊断能力；影子数据可以继续采集，但须按下述口径解释。

第一轮使三方能够在同一项目中表达结果，第二轮要使三方在同一项投资研究中协作：自动提出并检验假设，形成可接受的计划，识别变化，落实到有现金与成交约束的单一行动。新增一层总评分解决不了这个问题。

本结论依据：[实施报告](../ARCHITECT_REPORT.md)、[实施账本](../EXECUTION_RECORD.md)、当前源码、E0/E1/E5/E6/E7 报告及[本轮只读探针](PROBES.md)。保留原报告和历史 VERIFIED 记录，不篡改实施历史；**VERIFIED 只覆盖其中实际完成的验收条款，缺失条款在 R 任务中继续跟踪**。

优先级描述的是**下次连接与发布前必须处理的风险**，不是断言旁路能力已造成真实账户损失。

## 3. 对实施方五项设计选择的裁决

1. **有条件保留模拟影子计划。** 它用于诊断决策表，必须每周期标 `SIMULATED`，与真实已接受计划分开统计，不能计入采用率、效果样本或发布门槛。诊断模拟也不应把缺失事实假造为有效逻辑。
2. **认可“没有证据则 UNESTABLISHED”。** 但“有一条 facts 文本则 VALID”不成立。用户确认的是目标与风险意愿，不是将一句话变成客观事实；关键命题覆盖与反证处理由 R2/R3 计算。
3. **认可周期逻辑隔离，修正为“共享事实、分别评估”。** 同一财报是同一份事实，中长期都可引用。禁止的是把 MID 的评估结论直接复制给 LONG，不是禁止共享公司证据。
4. **不追认 E0 等价推断。** 保留“本人工案例集内差异较小”的描述。之后以明确冻结的修正臂为基线；另用定向场景验证 AI 方向和 T+1，不能因为未触发而沿用不正确执行语义。
5. **认可每股两套研究草稿；不认可覆盖历史与两个持仓主意图。** 同周期更新追加版本；已接受版本保持可回放。首版一个账户的一只股票仅一个 `active_holding_plan_ref`，另一周期仅供比较；切换必须展示差异后由用户明确选择。此处确认是产品中的投资意图选择，不是开发审批。

## 4. 三方怎样真正发挥强项

| 环节 | 笨韭 | 暮云 scan/技能 | AI | 统一结果 |
|---|---|---|---|---|
| 发现 | 产业链、业务受益、景气假设 | 广覆盖、趋势/回调候选、成交容量 | 将主题映射到可查证业务，补充反证 | 带来源和研究成本的候选并集 |
| 研究 | 谁受益、如何转化为利润、何时验证 | 提供市场是否已反映预期的价格证据 | 从原始文档提取事实、识别缺口与替代解释 | 共享证据上的 MID/LONG 两份逻辑评估 |
| 决策 | 提供持有理由与失效机制 | MID 择时与纪律；LONG 入场和风险辅助 | 检查新增事实是否推翻命题，解释变化 | 当前持仓意图对应的一个动作及触发条件 |
| 组合 | 不自己给仓位 | 提供波动与交易容量输入 | 不自己分配额度 | 已确认现金/份额、账户约束下的可行提案 |
| 持有 | 兑现进度、逻辑变化 | 趋势和风险变化 | 只提取新增文档/事件，不重复计分 | today 只突出需要用户处理的变化 |

`fear` 进入风险情景和研究优先级；`expect` 记录待兑现预期；`events` 记录事实结果；`watch` 保存等待条件；`diff` 展示改变动作的证据；RAG 提供方法而非当期公司事实。它们都引用同一证券/事件/快照/计划，不再各自产生一张买卖票。

关于“适合当前 A 股、因子是否强大”：目前可证明工程可用，不能证明跨市场状态的投资优势。现有归一化、双周期与约束方向可以保留；ROE/现金流比率/PE、60 日相对趋势、固定比例阈值均需按经济含义、行业和时点重新登记验证。**本轮不拍脑袋换一组更激进参数**，具体能力边界和实验见后两份设计。

建议一个数据负责人、一个研究负责人、一个集成负责人及独立审查者按任务卡分工；这是交接设计，本轮未启动新 Agent 或改产品代码。
