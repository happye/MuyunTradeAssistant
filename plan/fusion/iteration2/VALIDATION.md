# R7/R9 验证协议与发布门

2026-09-26｜设计，未执行｜本文件细化原 [VALIDATION](../VALIDATION.md)，并限定当前 E 报告的可解释范围。历史产物留存，补注不改写原数值。

## 1. 完成状态拆成五个维度

每项能力登记 `implemented / connected / scenario_validated / empirically_validated / release_ready`，每格只能是 PASS / PARTIAL / FAIL / NOT_RUN / NOT_APPLICABLE，附 commit、命令、产物、实际条款。NOT_APPLICABLE 必须说明为何本功能不主张投资效果。

例如：claim 提取器可 implemented=PASS、connected=PARTIAL、scenario_validated=PARTIAL、empirically_validated=NOT_RUN、release_ready=FAIL。工作台的风险可见性通过用户场景后可独立发布，不必冒充 alpha 已验证。某条验收未执行不能用单测总数递增补齐。

## 3. 冻结每次运行的真实信息集

原 E_SPEC 的单一 source_tag 不足以区分手工 mode、AI 当前提取、代理财务、严格历史。保留旧字段读兼容，新 manifest 至少包含：

```text
experiment_id, run_id, preregistered_at, started_at, completed_at
code_commit, dirty_tree_fingerprint, schema/adapter/policy/parameter_versions
universe_snapshot_ids, evidence_snapshot_ids, price/corporate_action/rule_versions
selection_source, mode_source, thesis_source, extraction_source
temporal_eligibility, unavailable_components, human_overrides
arms_and_single_variation, costs, budgets, exclusions_and_reasons
primary_metric, guardrail_metrics, inference_method, stop_rule, result_paths
```

`temporal_eligibility` 从每个输入的资格派生，不按实验编号硬赋。AI 用历史文本仍可能有模型训练期信息泄漏：结构提取只允许引用给定文本、不调用外部世界知识；保留 model/version/prompt，历史结果独立标签并辅以前瞻验证，不能因为没有联网就说绝无前瞻。

任何人工挑选案例、人工 mode、参数试验次数、剔除失败记录都在 manifest 中可见。同一天截面不同来源抓取存在时间差，要固定 cutoff 与最大允许时差，不默认“同一天就是同时点”。

## 4. E0–E7 下一版具体设计

### E0b 正确性冻结，不以收益无差证明没有问题

双臂使用同输入、同冻结日历与价格。定向构造：同日买入后退出、老仓可卖/新仓不可卖、末日尚不可卖、AI 看空对 SELL 强度、硬风险被 PlanGuard/技术持有覆盖。逐笔比对动作意图、可卖数、拒绝原因、现金/持仓守恒和终态文本。

定向场景不是历史策略效果样本；历史案例只是补充回归。正确性差异按原因逐条解释，不能用收益差<2pp 豁免执行错误。修正臂通过后冻结 manifest 和 hash，不再为后续策略结果好看修改基线。

### E1b 候选召回：同等资源下有没有额外的合格机会

先做当下可得性实验：同一冻结市场全集、相同证券排除规则、同一 cutoff，预设研究总名额和 AI/抓取预算。每路记录原始返回、有效实体、去重、配额前后、数据缺口和每个阶段时间/费用。

技术/产业/质量三路可有不同方法，但资源比较必须声明：分别报告“相同深研究名额”与“相同实际成本”两种口径。质量路仅抽60只时只能与相同抽样集合比较；不得拿全市场50只和抽样5只比较能力。

主要工程指标：有真实业务/质量证据且满足研究资格的独有候选数、每个合格候选的成本、严重漏检与重复率。集合交集/Jaccard 只作多样性描述。只在严格历史股票全集/退市成员齐备后计算未来收益、风险与机会覆盖；没有“全体真实机会”标签时不能把 top-N 命中率称全市场 recall。

法C 分片按产业链环节/证据查询任务进行，合并后去重；每片带覆盖范围、token 上限、截断状态。分页不是让 AI 无来源生成更多代码；结构非法或末尾截断的实体不进入已验证候选。预算耗尽给部分覆盖标识，不重试到无上限。

### E2b 研究资格增量

共同候选集合、同一研究截止时点、相同后续交易政策。对照：无新增资格门 vs MID 资格门 vs LONG 资格门；周期分别报告，不能把长期门淘汰的短线爆发当统一失败或成功。

固定其余评分/择时/预算。被拒候选仍保留 shadow outcome，检验误杀与风险过滤；新增门只改变选入，不能同时改变止损后归功资格。财务若只有 latest-only，允许当前截面资格审计，**不执行严格历史收益结论**。

结果：覆盖率、拒绝原因、入选/未入选分布、分行业/市值/年代的风险与收益。先预注册主要持有窗口，再固定辅助窗口，例如20/60/120/250交易日可按研究周期选取；它们是待冻结实验窗口，不是自动交易参数。

### E3b 持有纪律增量

同一批达到相应资格的标的、相同入场时点和初始资金，对比 legacy/对应周期新纪律；先分别检验 MID 与 LONG，避免用不符合 LONG 资格的全体股票检验“长期好不好”。控制建仓选择和择时，记录每次 sell_path、逻辑失效、技术退出、复核到期与受阻。

度量收益/回撤之外，还计换手、过早退出后机会损失、已知失效后滞留时长、最大资金占用与长期逻辑未经验证而持续持有的比例。强制窗口末日估值与真实可卖数量分开，不为结算指标虚构卖出。

### E4b 技术择时增量

同一资格候选、同样计划目标/退出纪律，对比：无技术择时的预设可交易时点 vs 技术条件入场/加仓。未触发保留现金，并统计等待时间、错过机会和现金拖累；不能只评价最终成功入场者。

LONG 分批入场与 MID 趋势时点分别设计；使用相同规则版本的交易限制/费用。技术参数、风险阈值与市场状态切换必须在训练区冻结，样本外保持不变。

### E5b AI 的证据与决策价值分两层

第一层冻结人工核验语料：公司/时间切分，正文、出处、预期事实和拒识理由冻结在运行前；不得看到模型拒识后改正确答案再宣称同一测试通过。旧 f6.v1/v2 各自保留成绩。

指标：事实 precision、关键数值/单位/否定/阶段错误率、重大反证 recall、可回答样例的覆盖率、应拒识样例的拒识率、错误拒识率、单位事实成本。拒识不是越少越好：无材料拒识正确，有充分材料却拒识需计覆盖损失。先用有边界的标注扩展，8条仅保留回归作用；样本量由目标误差与置信区间决定，不用一个漂亮百分比代替不确定性。

第二层冻结相同快照/候选/计划：A=确定性材料路径；B=A+LLM提取；C=B+独立反证检索/核验预算。反证臂不能把所有 statement 的 relation 机械翻成 REFUTES。使用真实留存的 LLM 输出和真实成本，失败/拒识也入分母。

比较：有正确新增事实造成的合理动作变化、错误变化、重大风险漏检、未改变决策的冗余调用、每个有效变化成本。投资结果另在时间安全的闭环或前瞻组上报告；**产出更多 claim 不算成功**。

### E6b 组合预算与执行

拆成两个实验：固定**事前动作意图**流验证分配/成交机制；独立完整状态回放验证不同预算导致仓位差异后策略反馈。不能把旧臂实际成交清单作为完整系统两臂共同意图，因为已执行交易已受旧状态筛选。

删除未来全区间最大回撤输入；采用当时可得窗口的估计或预注册固定压力场景。当前行业归属只能用于 contemporary 子实验；无历史成员表则该历史行业约束声明未验证。现金、费用、分红/除权、IPO/停牌/退市、规则生效日期按 R6 接入后才升级真实回放资格。

主要门：现金/数量守恒；买入时约束违规0；已确认现金不重复计算；未知现金不给可执行精确数量；合法申报粒度不发生“预算通过但因同一已知粒度规则再拒绝”；旧持仓风险占用计入预算。漂移超配单独报告。收益和回撤是结果维度，不要求强约束模型在每个牛市样本收益都高于无约束模型。

### E7b 完整系统

先运行全链受控场景，必须有 OPEN、ADD、HOLD、REDUCE、EXIT、WAIT、REVIEW，以及 EXIT+BLOCKED/UNKNOWN 的实际路径命中证据。预算至少包含一个可行新增、一个不足最低合法申报、一个现金不足、一个因未确认卖出不能释放现金的案例。

场景测试用合成输入明确标注，绝不为让真实候选出现 BUY 改资格或入口条件。随后做同 cutoff 的当前真实非空路径观察；若真实市场尚无某类路径，标 NOT_OBSERVED，不计已通过。

最终对照至少包含正确性基线、各单能力臂、完整融合臂；检查交互作用，避免 E2/E3/E4 改多项后将收益归功任何单一组件。中长期分别报告。资料不足则以明确期限的前瞻采集积累，不能补当下 AI 观点到历史数据中。

## 5. 统计与停止纪律

股票/日期重复与多窗口重叠会相关，不能把每根 bar 当独立样本。预先定义按时间块、证券或两者分组的推断方法；滚动训练/验证/测试分离，跨窗口标签做相应隔离。参数搜索总次数与失败尝试留存，遵循原验证方案的多重比较约束。

主要指标与最小经济差异在看结果前冻结；置信区间过宽结论就是证据不足。平均收益之外必须分市场阶段、行业、规模、流动性与周期；样本稀疏分组只报描述统计。更优收益不能抵消已确认的时点泄漏、账本错误或不可执行交易。

研究预算单独冻结：证券数、日期范围、总 AI tokens/请求数、外源请求上限、失败重试上限、预估最长时间。超限停止受影响实验，保存中间状态；不静默扩大网络/AI 调用以凑够成功结果。

## 6. 影子统计改为可解释的配对样本

以 `(security, horizon, plan_id, revision, snapshot_id, account_version, policy_version)` 记录一条周期决策。每周期单独保存 plan_source 与 thesis_status；MID 真计划、LONG 模拟不能合并为一个 user_plan_accepted。

比较要求：同 cutoff、同账户事实、可对比的主意图、相同执行规则；只比 desired_action 不足，还要比较执行资格、目标数量/权重、关键 blockers。不同范围/缺输入记 unmatched，不纳入有效一致率分母。

三类分开报告：诊断模拟、真实草稿、用户接受计划；同样输入重复分析只计一个独立评估样本，仍可单列重试与运行稳定性。全部 REVIEW/WAIT 会导致差异小，必须同时报决策覆盖、关键状态命中、缺口原因及非空行动数。

## 7. 发布门和停止条件

`fusion.shadow_capture` 是捕获开关，不是 opt_in 的同义词。建议独立的 `fusion.mode=legacy_only|capture_only|shadow|opt_in|default`，由单个配置解析器迁移旧开关；这是待实施接口，不是假称现已有该设置。

| 发布范围 | 进入条件 |
|---|---|
| 可信数据提示/计划草稿/界面改善 | 对应 R 场景通过；不改变投资主结论；能降级且来源清晰 |
| shadow | 隔离模拟/真实、账户不变、日志可恢复、差异配对口径明确 |
| 融合主决策 opt_in | R1–R6 正确性门通过、R8 八类用户任务通过、关键正向/拒绝路径覆盖完整、真实接受计划有足够独立观察；未知经济优势明确披露 |
| default / 宣称策略效果改善 | 在 opt_in 基础上，对目标周期/适用范围满足原经济显著性与风险门，样本外及前瞻证据达到预注册标准 |

opt_in 初次运营观察的**提议下限**：20 个交易日期、每个拟启用周期30个不同证券-计划版本组合、至少10次有新证据的复评。此数仅防“运行一天即稳定”，不是统计功效证明；不鼓励用户制造无意义计划凑数。若用户实际持仓不足，保持有限研究试用/延长观察，以真实覆盖和预注册不确定性决定是否晋级。合成稀有风险场景可以证明处理逻辑，不伪装成真实市场命中。

硬门：已知高危事实被压住、证据伪升级、持仓/现金污染、旧修订回填、可执行性虚标，任一确认即暂停受影响能力晋级。0错误也要报分母/覆盖，0/0 不是通过。回退只切策略入口，事实分离、终态一致性、安全门和历史账本保留。

最终 R9 出具逐条 PASS/PARTIAL/FAIL 的发布建议；实现 Agent 不能仅依据影子差异率连续稳定自行宣告 default。源码清理与性能收益另报，不与投资收益混算。
