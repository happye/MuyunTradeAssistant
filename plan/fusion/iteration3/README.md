## 1. 三条路线的决定

**接线批优先，先完成语义安全小批次；前瞻原始数据采集同步开始；严格历史资料先做有预算的原始档案试点。** 三者不是互斥选择，也不让用户空等20个交易日。

顺序：J0研究/事实单一真值、J1数据映射边界 → J2账户确认闭环、J3单股研究/计划主流程 → J4合格影子观察；J5分阶段补实验证据。J1原始留存可立即按现有能力推进；只有过资格门的样本才进有效研究/影子分母。

目标：`l/research`提供可保存、可复核的研究和计划；用户接受后，`today`展示有账户约束的建议，`pos confirm`记录实际成交，再分析从已确认事实继续。legacy主决策继续保留，融合效果未达门槛不替换它。

## 4. ISS-114裁决

**认可保留raw和版本化纠正的架构；不认可“双样本证明全市场永久统一÷100”。** 本轮盘点：768个逐字段归档对象，只有000002/600519两家公司；liabilityToAsset共24个观测。不是768家公司或768个独立资产负债率样本。

`cross_checked_pending_original`应保留并传到派生资格，不能只放semantic_note。两个供应商交叉一致不证明发行人原件完全一致。映射仅按adapter版本+报告期下界，无法覆盖供应商再次改口径的风险，须J1补齐后再作为合格长期风险输入。

[DATA_DECISION](DATA_DECISION.md)已排顺序：先核定正在用的负债率、流动/速动比率和资产权益倍率，再处理其余balance字段。样本核定只支持对应范围；也不能回退为已知可疑原值后当正常数据使用。

## 5. 发布与观察期

- 已验证的资格提示、缺口说明、实验性research继续使用；保留全部原始资料和计划。
- J0/J1/J2完成前，不把新研究/数量模型接成权威动作，不扩大可执行性声明。

- 上轮20交易日/30证券-计划组合/10次复评是运营观察提案，**不是要求单个用户凑30份计划，也不是统计充分条件**。本轮按能力冻结观察协议，区分有限试用与默认发布。
- 非行动研究界面不必等严格收益实验；融合主决策仍不晋级。合成通过不能代替真实中长期效果，0/0不通过。
