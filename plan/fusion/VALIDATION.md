# 融合系统验证与发布门槛

2026-09-25；全部是后续实施要求，**本轮没有完成这里的回测或产品验收**。本轮已运行的局部探针仅见[PROBES.md](PROBES.md)。验证负责人独立于策略参数实现负责人，允许一个Agent分阶段承担但须保留冻结记录。

## 1. 三种成果分开验收

| 成果 | 可证明的事情 | 不能代替 |
|---|---|---|
| 正确性 | 终态一致、无未来数据、持仓不被建议改写、同输入可复现 | 不代表盈利 |
| 可用性 | 用户知道下一步、失败可理解、耗时费用可控 | 不代表选股有效 |
| 投资效果 | 指定信息集、样本、成本与约束下优于预先冻结基线 | 不保证未来盈利，也不代表另一周期有效 |

修复安全缺陷后可能降低历史收益，这是修正隐含风险敞口；不为保旧收益恢复错误行为。收益实验须单列“修正前legacy”“修正后正确性基线”“新策略”，避免把修复的影响算成策略优势或劣势。

## 2. 先建数据资格表

每个实验保存manifest：代码提交、配置/参数hash、依赖版本、数据源版本、as_of、交易日历、费用规则、样本集、纳入/排除原因、缺失比例、AI模型/prompt、试验编号、冻结时间。

| 项目 | 通过条件 | 不通过时 |
|---|---|---|
| 股票池 | 每个历史时点知道当时上市/退市/ST及行业归属；保留后来消失的股票 | 只能称存续样本案例研究 |
| 财务 | 报告期、首次公布日、可用时点、重述版本可区分 | 不用今天财报或任意延迟天数伪装PIT |
| 行情 | OHLC/量额与单位、除权分红口径、停牌、异常记录说明 | 不让缺失价格等于零收益，也不直接剔除失败股 |
| 成交 | 下一可交易时点；已买份额T+1；限价、数量、滑点与费用可追踪 | 只报告信号统计，不称交易收益 |
| AI | 使用当时记录输出，或明确历史模型知识污染限制 | 历史LLM实验仅作辅助研究，不作上线收益证据 |
| 产业/事件 | available_at先于决策；当时行业映射和公司暴露 | 缺时点依据的维度关闭，报告信息集与live差异 |

复权价用于收益/技术指标的规则需统一；成交价、数量、股息、拆分单独处理，不能用含分红复权收益后再加一次股息。停牌/退市期末估值有明确政策和敏感性结果，不能丢弃亏损尾部。期末持仓默认市值计价并另报清算情景，不利用期末已知价格安排提前成交。

数据源初始探查可按主板/创业板/科创板、行业、市值、上市年限分层抽样；抽样只证明可得性，不能替代全量覆盖。复用已有数据缓存，不默认对全市场逐日调用六维AI。

## 3. 实验矩阵：三方各自贡献必须可拆

先注册假设与主指标，再看收益；新增尝试追加编号，失败试验也保留。

| 实验 | 固定什么 | 改变什么 | 回答什么 |
|---|---|---|---|
| E0 正确性基线 | 同一历史快照、旧策略参数 | 仅终态/事实持仓/执行正确性修正 | 旧收益含哪些错误或执行差异 |
| E1 候选召回 | 同时点市场全集、研究预算 | 技术单路、产业单路、长期质量单路、并集配额 | 有效机会覆盖是否增加，是否只是多看更多股 |
| E2 投资逻辑资格 | 同一候选集合、相同入场/退出 | 无资格过滤、bz旧分、证据资格 | 产业/公司研究是否有增量，拒绝了哪些机会 |
| E3 持有纪律 | 同一事前候选与入场日 | legacy、fusion_mid、fusion_long（分别报告） | 收益/回撤/换手改善是否来自周期纪律 |
| E4 技术择时 | 同一投资逻辑和预算 | 固定周期分批、技术触发、混合门控 | 技术层能否改善成本、风险或机会捕捉 |
| E5 AI | 同一证据、计划、预算 | 无AI、结构化提取、提取+反证；旧modifier作独立对照 | 是信息增量还是重复技术/新闻，净收益是否覆盖费用 |
| E6 组合 | 同一单股动作集合 | 逐股建议对照、统一资金与集中度约束 | 是否减少不可实现仓位和集中风险 |
| E7 完整系统 | 同一PIT全集、成本、研究资源预算 | 修正后基线 vs 完整融合漏斗 | 真实产品流程的净效果，不只择优子集 |

E2–E6配对对照控制选股偏差；E7允许候选不同但预算相同，同时报告数量与覆盖率，不能只保留“双方都成功”的股票。bz规则代理、AI原版、人工指定mode必须分开，不能合并为同一策略名称。

基准至少包含：同一候选的买入持有、简单可解释策略、宽基总收益基准及合适的行业/风格参照。沪深300可保留用户熟悉口径，但小盘科技策略仅超过沪深300不足以证明选股能力。

## 4. 时间划分与统计

- 优先覆盖多个涨跌/震荡阶段与行业周期；具体起止由PIT可得性决定。既有人工挑选2020–2026案例是开发/回归集，不再当未见过的样本外集。
- 使用按时间前推训练/验证/测试；阈值、标准化、行业分位和缺失处理只在训练窗口拟合。长持标签跨界要purge重叠，embargo由真实标签观察长度决定，不机械套短期5天。
- 模型、规则与参数冻结后才进入测试窗口。2026年尚未走完的时期不报告全年成绩；自本次冻结后开始积累前瞻影子数据。
- 同日多股与同股重复扫描并不独立。收益路径按日期块抽样，横截面考虑股票/行业聚类；报告有效独立决策期和置信区间，不把一千个重复股日当一千次独立胜利。
- 同时展示收益、超额、最大回撤、回撤持续时间、下行风险、换手、平均/尾部持有期、成本、现金暴露、行业集中、未成交率、拒绝覆盖率。
- 因子测量用事前Rank IC、分组单调性、覆盖率与行业/规模暴露；标签只看指定未来窗口且剔除不可交易假设。IC不能代替可实现组合收益。
- 收益分布不正态时不能只报普通t值；试验登记与多重选择修正可参考DSR，但它不能修复坏数据和事后选股。[方法来源](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

不设置一个随意的“100笔就足够”门槛。先用开发集波动与策略持有长度做功效评估，再冻结所需样本与经济显著性门槛。证据不足如实记INCONCLUSIVE，不为赶发布用短期数据证明长期策略。

## 5. 参数治理

| 参数类型 | 处理方式 |
|---|---|
| 市场法律/制度参数 | 官方来源+生效日期；不参与优化 |
| 用户风险界限 | 用户设置/明确接受的档案；禁止以提高收益为由自动放宽 |
| 教学保真参数 | legacy原样保留、版本化；v2变动新策略ID |
| 研究阈值 | 经济解释、训练期选取、邻近值敏感性、样本外冻结 |
| 性能预算 | 基于实际耗时/费用基线；不能以预算为由让必需风险证据静默跳过 |

每个参数登记旧值、来源、适用周期/行业、预期作用路径、实际触发次数、新值、实验ID。先验证参数真的影响当前sell_path或资格条件；遵守项目同族调参连续两次无显著改善后停止第三次盲调的纪律。

推荐研究方向是减少不稳定阈值：如流动性用可交易量与相对分位，价格偏离同时看ATR及百分比；是否优于旧阈值由实验决定。不要为每个牛熊阶段堆一套高维参数表。

## 6. 必须通过的工程场景

| ID | 场景 | 必须出现的结果 |
|---|---|---|
| G01 | entry_exit卖出被计划守卫压制 | 最终卡显示HOLD并说明压制；原始卖点只在诊断 |
| G02 | 无原始卖点，后置止损/到期/基本面硬退出 | 所有入口显示EXIT意图，无“今天什么都不用做” |
| G03 | EXIT但跌停/停牌/无可卖份额 | 持仓数量成本不变，退出待办保留，执行状态受阻 |
| G04 | 技术强买但景气必需证据缺失 | 研究不完整、禁止新增风险，不靠50兜底发买入 |
| G05 | 长期质量通过但过买价区间；中期有买点 | 分周期给不同研究结论，当前持仓意图不自动切换 |
| G06 | 长期逻辑破坏但价格反弹 | 不用技术强势抵消已核实反证 |
| G07 | 同公告经bz/events/modifier/chat多次使用 | 保留多个用途但单一事件谱系，不能重复加票 |
| G08 | 财报修订、发布晚于截止日、行业历史归属变化 | 历史重放不出现未来信息 |
| G09 | 批量十股均建议增仓，现金只够两股 | 统一预算，顺序置换结果相同，拒绝原因明确 |
| G10 | 手工改持仓后重跑当日缓存 | portfolio_revision变化使旧建议失效 |
| G11 | 当天加仓后卖出旧份额 | 可卖量按交易批次；不能把全仓当日锁住或允许全卖 |
| G12 | 分析中断、重复录入成交、并发更新 | 不伪造成交、不重复入账、不覆盖别人更新 |
| G13 | AI超时/畸形JSON/引用不存在/正文注入命令 | 核心风险卡可用，坏claim被拒，秘密与写工具不可被调用 |
| G14 | legacy数据缺版本、坏JSONL行、旧计划未知字段 | 缺字段显示未记录，原文件与未知字段不被丢弃 |
| G15 | 当日盘中量比与日终日量比混合 | 口径不能互换，未满足同口径标INCOMPLETE |

实现时需要纯函数测试、真实parser→service接线测试、临时home持久化测试三层。最终做REPL/CLI/chat/Web/TUI消费者矩阵；不要只mock `_print_plain_summary` 就判终态一致。

## 7. 用户验收和性能

用上述真实语义制作至少8种任务卡：继续持有、等待买价、证据不足、退出受阻、周期冲突、预算不足、旧计划迁移、新反证出现。首轮由用户走查，条件允许时再找3–5位非开发读者；不把小样本体验结果当统计结论。

预注册目标：普通卡在30秒内能正确说出“下一步、主要原因、改变条件”；不能误以为建议已成交。所有硬风险场景误解数必须为0；失败即改呈现再验。首页减少信息以理解任务完成为准，不以字符越少越好为准。完整报告链接与数据时点不可丢。

先测当前单股冷/热缓存、20股批量的p50/p95耗时、外部请求、AI调用与费用、失败比例。新版对相同证据的重复分析应零重复AI，价格变化仅重算受影响层；新公告/新计划/持仓更新不得命中旧决策。端到端预算到期返回真实已完成部分及未完成项；不能用后台线程继续占资源却显示任务已取消。

## 8. 发布与停止条件

1. **正确性发布**：G01–G15中本批受影响场景全部通过，离线回归通过，旧安全网完整；不需要等待收益改善。
2. **研究功能发布**：数据资格/来源可追溯、缺失状态准确；允许实验研究，但醒目标明尚无效果证明。
3. **新策略默认启用**：冻结测试集上的成本后主指标达到预注册的经济显著性门槛，风险不突破既定上限，关键分层没有无法解释的退化，前瞻影子输出稳定。长期结果观察期不足时保持opt_in，不用中期成绩替代。
4. **回滚/降级**：发现未来数据、持仓事实污染、重大风险被摘要隐藏、来源凭空生成即停止该路径晋级；保留已有记录，用正确性基线服务。

策略收益未达标不等于整个项目失败：保留证据管理、持仓安全与易用性成果，减少无增益因子，解释失败来自哪个环节。禁止事后改主指标或删除不利行业后宣布成功。
