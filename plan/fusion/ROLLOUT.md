## 3. 停止/回滚条件（VALIDATION §8 第 4 条，任一触发即停该路径晋级）

1. **未来数据**：任何路径发现 available_at 语义被绕过（F3 闸门被旁路）
2. **持仓事实污染**：建议/观察量写入路径改动了已确认数量/成本/开仓日期（F1 不变量）
3. **重大风险被摘要隐藏**：终态输出丢失硬退出/受阻退出意图（F2 PROBES A/B 回归）
4. **来源凭空生成**：claim 引用无法在证据库定位（F6 核验被绕过）

回滚动作：切回旧策略计算（settings 开关或 git revert 对应批次）——**持仓事实分离与
动作一致性属于安全性修正，独立保留，不随回滚撤销**（TASKS F5/F2 回滚条款原文）；
新计划版本、证据与成交日志不删除，未知字段保留（ADR-F09）。
