初查基线 `449bbfb`，2026-09-25恢复核对HEAD为`bdebf13`，两者仅start.py帮助菜单变化，以下核心源码一致。行号仅定位线索，后续以符号及当前源码复核。本文的“提案”均未实施；历史数值来自仓库记录，本次没有重跑收益回测。

## 1. 笨韭框架实际在做什么

### 1.1 公式、等级与定模式

`src/core/benzong/scorer.py:116`：

```text
R = 0.20*景气 + 0.40*纯度 + 0.25*历史价格位置
    + 0.15*细分龙头 + 0.20*辨识度 - 0.20*风险
total = round(R * L, 2)
L = 0.8 / 1.0 / 1.2，对应全市场成交额 <=0.8 / 中间 / >=1.5 万亿元
normalized = clip(total / (1.20*L), 0, 100)，最终取一位小数
```

`grade()` 原始 A/B/C/D 阈值为 90/80/60/40；`effective_grade()` 另加风险否决、景气≤0 判 F、≤30 最高 C、≤50 最高 B。**归一化分取消了流动性系数的主要影响，等级却仍基于乘过系数的原始分。** 实际探针：正向五维全 80、风险 0，成交额从 0.7 到 1.0 万亿，展示同为 80 分，等级 C→A。这是现有双口径的结果，不擅改保真公式。

`trade_plan/generator.py:71 _mode_from_grade`：A 且景气未失效可为气宗；S3/S4 或自主可控标签改剑宗；B 为剑宗；market_state 参数保留但不参与。缺 stage 不等于通过长期质量评估。后续更新由旧 mode 反推，不是重新检查完整投资逻辑。

### 1.2 六维的强项与盲区

| 维度 | 已核实实现 | 有用之处 | 不应推断什么 / 融合提案 |
|---|---|---|---|
| 行业景气 | `dimensions/industry_prosperity.py:19` 提示词仍以二级市场景气为中心，已有商品/需求/宏观客观桥接；缺客观证据时回到新闻并限制模型自报 confidence | 催化剂与产业方向检索 | 拆成“经营景气”“市场热度”“预期差”；报道多不能代表订单兑现 |
| 业务纯度 | `business_purity.py:14` 营收占比分档；输入主要为主营介绍，海外占比影响评分 | 防蹭概念、定位真实受益业务 | 主营文字不能证明分部营收占比；需要报告期、分部口径、公告页码。纯度不是 ROIC 或护城河 |
| 历史估值位置 | `valuation_position.py:17`：距近三年最低价涨幅≤20%约满分，≥120%零分，中间线性扣分 | 价格位置与追高提醒，确定性可计算 | **未计算 PE/PB/现金流估值**。下跌不等于便宜，优质长期上涨不等于昂贵；新版旁列真实估值，旧公式不动 |
| 细分龙头 | AI 结合产业地位叙述，规则代理以市值分档 | 建立竞争地位假设 | 市值不是份额、定价权、客户粘性或资本回报；必须明确份额时间与细分市场定义 |
| 市场辨识度 | AI 语义判断，规则代理换手与成交额 | 区分研究关注度和题材传播 | 关注度可能同时代表拥挤，不能一直线性奖励；热度不宜作为长期质量分 |
| 风险扣分 | 新闻/公告 AI 识别，缺失有兜底提示；风险否决传到等级 | 文本风险检索 | 缺新闻不是无风险；单一模型标签不自动视为已证实造假；确定事件和解释推断分开 |

`auto_scorer.py:243` 后：缺成交额使用中性系数；缺维度可带 50 兜底参与数学结果；整体 confidence 取六维最小值，并有降级警告。已有提示不能替代机器层研究资格闸门。新版保留旧分作为诊断，同时对必需证据不足返回 `INCOMPLETE`；不把旧数学分悄悄改成另一公式。

### 1.3 历史研究到底支持什么

- `ISSUES.md:999`：五股规则版/AI 版 Spearman 0.600，业务纯度/辨识度/风险三维为 0，记录本身否定“规则版逐日等价 AI”路线。样本很小，不能精确估计总体相关性；足以否定把代理版当作验证完毕的 AI 版。
- `ISSUES.md:1115` ISS-046：气宗案例按人工指定 mode 做 A/B，有些牛股样本改善，有调整年/小盘样本恶化。2026 批次记录承认依据已走完行情标注模式。
- 后续安全网与纪律修复改变结果，ISS-074 及最新源码才是待重建基线，不能引用旧“+12.32pp”等数字证明当前自动选股系统有效。
- `backtest_engine.py:272 _resolve_benzong_mode` 当前切到建仓时点 K 线，缺 PIT 公告/主营/快照显式置空，这是正确的防未来数据措施；也意味着回测信息集与 live AI 明显不同。code 级缓存还需明确“一次研究周期”还是整个回测固定模式。

结论：**有值得保留的持有纪律和行业研究方法，尚无足够证据证明现有六维总分能稳定转换成中长期超额收益。** 应分别验证产业候选召回、事前逻辑识别、持有纪律与执行质量。

## 2. scan 与暮云策略的真实能力

### 2.1 六种扫描是候选生成器

事实源 `src/scanner/scan_rules.yaml`。主行情源没有量比时，`scanner_filter.py:97` 会 warning 后跳过整列缺失条件；单元格 NaN 在比较中通常被剔除，二者语义不同。不是所有候选都满足规则名称的完整含义。

| 规则 | 当前主要参数 | 融合定位与实验要求 |
|---|---|---|
| healthy_pullback | 跌幅 -3%~-0.1%，量比<1，换手1%~10%，振幅<6%，成交额>1亿，最多30 | 中期回调候选；必需量能证据缺失不得宣称“确认缩量” |
| shrink_pullback | -5%~-0.1%，量比<0.8，换手0.5%~5%，振幅<5%，成交额>0.5亿 | 与上一规则重叠需去重；先回调不代表已企稳 |
| steady_advance | 0.1%~5%，量比1.1~3，换手1%~12%，振幅<7%，成交额>1亿 | 趋势候选；不能推广到所有板块同一最佳阈值 |
| value_pick | PE 1~20，PB 0.1~2，股价>3，换手>0.5%，成交额>0.5亿 | 价值候选，不是质量认证；银行与科技不能直接横比，亏损公司需独立研究口径 |
| theme_members | 股价>2，成交额>0.2亿，最多80 | bz 的宽口径主题召回，保留二线与小盘，不能只依赖 AI 熟悉名单 |
| oversold_watch | 跌幅≤-5%，成交额>0.5亿，股价>2 | 高风险特殊研究队列；不因跌多自动进入长期买入名单 |

`scanner_engine.py:223` 已有缺排序列的富集与告警机制，不应重开“完全没排序”的旧问题；富集预算超限时的降级仍需记录到候选集元数据。

候选截断影响后续 bz 排名上限：先丢掉的标的，后续再强的 AI 也找不回来。新版用技术、产业、长期质量三路**并集召回+去重+来源配额**，不要求一只长期好公司恰好今天下跌才有资格被研究。

### 2.2 深度技术分析不是 scan 快照本身

实际生效配置在 `configs/settings.yaml:158 entry_exit`，不是已废弃的 `src/core/entry_exit/config.yaml`。`entry_rules.check_breakout` 用 60/120 日高点、20 日均量倍率及 MA5>MA20>MA60；`check_pullback` 结合 MA20 距离3%、量能<0.8、20日涨幅>10%和均线排列。Chandelier、trend_break、StrategyLayer、PlanGuard 共同影响卖出，调 exit_rules 并不等于改变实际 sell_path。

优点：规则可重复、无需模型主观回答，已有下一交易日执行、T+1、税费、滑点与限价约束的回测基础。限制：趋势窗与倍数是既有策略设定，不是当前 A 股已证实最优参数；常见 MA、RSI、阶段、价格位置来自相同价格序列，不能算四份独立证据。

`decision_engine.StateMachine` 混合个股急跌 PANIC 与指数长均线状态。提案拆为 `market_regime` 与 `stock_stress` 两个证据字段；市场风险影响总预算，不简单取消全部独立行业机会。既有 ISS-065 的阶段双口径与气宗/Chandelier 裁决维持 legacy，变化须实验。

## 3. AI 与当前动作链的语义风险

### 3.1 可定位的事实

| 发现 | 代码位置 | 验证层级 / 影响 |
|---|---|---|
| score 是选定动作桶强度，SELL 还有动作置信度兜底 | `decision_engine.py:270` 附近 | 源码事实；不是预期收益或上涨概率 |
| bearish 统一产生负 adjustment；没有输入当前决策方向 | `ai_modifier.py:351 _apply_modification` | 隔离探针：confidence=.8、weight=.3 → -.24；若作用于 SELL .8 则变 .56；完整终态后果需集成回放 |
| 主编排将 adjustment 加到通用 score | `orchestrator.py:233`、`:270`、`:294` | 源码有不同分支；不能误说这三行每次全部执行。必须按实际分支测试 |
| 技术分直接 score×100，另一维又计 AI sentiment | `ranking_layer.py:180` | 探针 SELL .9→90，BUY .6→60。该分量不能当买入排序依据；总榜次序还取决于其他分量 |
| AI 已结合技术背景，提示词要求方向同则放大，矛盾时以技术为准 | `ai_modifier.py:41 SYSTEM_PROMPT` | 源码事实；容易技术信息重复计入及压低独立反证 |
| 摘要取 raw result 与 entry_exit，未接 execution_eval | `cli/main.py:1568 _print_plain_summary` | A/B 探针已复现终态相反文案；未量化真实发生率 |
| 证据卡 decision/score/position_ratio 与 position_action 来自不同阶段 | `cli/evidence.py:26 record_evidence` | 源码事实；跨版本语义“保持稳定”还需明确字段所属阶段 |
| 分析后回写可改变记录比例、清空入场信息 | `data/portfolio.py:532` 附近 `update_from_strategy_decision`；chat/tools.py:366、web/app.py:122、tui/app.py:209 | 静态调用链确认；本次未触碰真实持仓，需临时目录端到端验证 |

现有安全网已多次修复，不能因为找到 score 语义问题就推断所有止损已失效。此次必须先锁行为，再实施带完整路径证据的修复。

### 3.2 AI 的重新定位

第一阶段不再新增模型投票。统一提取“谁、何事、发生时间、公开时间、影响业务、是否新增、支持/反驳哪条逻辑”，由规则验证来源与时点。再用一个解释器描述决定行动的证据。正反观点可以由同一模型生成以提高审查覆盖，但不按模型数量增加可信度。

产业评分、events、expect、AI Modifier、chat 共享事件 ID 和源文档 hash；同一公告被转载十次仍是一份经济事件。模型不能用提示词中的交易建议覆盖最终动作。财报数据与新闻是数据，嵌入的指令忽略。

## 4. 参数是否适合当前 A 股：逐类回答

外部依据见 [MARKET_EVIDENCE.md](MARKET_EVIDENCE.md)。本次没有完整最新行情快照，**不判断当前全市场牛熊或某行业“现在最强”**。

| 参数家族 | 当前判断 | 下一步，不直接调默认值 |
|---|---|---|
| 0.8/1.5万亿流动性系数 | 固定名义成交额随市场规模变化有漂移；归一化分与等级响应不同 | legacy 保真；新风险预算比较历史成交额分位/自由流通市值换手，按当时可见样本计算 |
| 20日涨幅代理行业景气 | 价量与经营因果错配，也重复了技术因子 | 标记 price_proxy；不能宣传规则回测验证了 AI 产业判断 |
| 三年低点20%/120%扣分 | 衡量价格位置；与长期复利存在潜在冲突 | 独立考察追高风险，不当估值硬否决 |
| 纯度权重0.40、海外占比折扣 | 教学规则，有解释性；未提供当前广泛样本外优势证据 | 保留原体系；新版用可核实的业务暴露/盈利贡献，不机械否定海外收入 |
| 自主可控标签强制剑宗 | 既有纪律，但主题标签无法充分区分订单、利润及估值 | legacy 不动；v2 对实际业务质量、波动与投资逻辑分层验证 |
| PE<20 / PB<2 | 有价值研究意义，但行业会计差异、周期利润和负值易误导 | 行业内与历史口径，盈利质量联检，亏损企业转专门研究而非填0 |
| 量比0.8/1.5、MA窗口 | 可解释且可复现，但不等于普适有效 | 候选漏斗命中率+成本后收益，测试邻近区间稳定性；盘中量比与日终日量比严格分开 |
| 单日-5%恐慌 | 主板/创业板/科创板相同百分比含义不同 | 分开法律涨跌幅限制、个股历史波动、市场压力，避免误称系统性恐慌 |
| ATR止损 / 180与30自然日 | 已有历史行为约束，适合做纪律对照 | 保留 legacy；新周期计划区分复核日、催化到期、硬风险阈值 |
| 模型confidence与总评分 | 未做概率校准；最低维 confidence 能暴露缺失但不等于收益可靠性 | 改为证据覆盖、来源质量、矛盾/时效；验证前不展示“上涨概率80%” |
| fear / expect | 市场情绪和事前预期的有用上下文 | 改预算或复核优先级须实验；不与价格/新闻再次相加，也不凭恐慌分自动抄底 |

研发优先级：**动作一致性 → 持仓事实 → 数据时点与资格 → 周期逻辑 → 组合预算 → 增量效果**。数据不足时加更多因子只会增加难以解释的误差。
